# 四足轮腿机器人 IMU 姿态自稳实现说明

> 适用硬件：12 路舵机 + 4 路轮电机，IMU 为 WT9011G4K（UART 10Hz 主动上报）。
> 本文档描述**已实现的站立自稳**（attitude_control.c/h），非设计稿。

---

## 1. 功能概述

站立自稳：机器人在倾斜地面站立时，通过 IMU 姿态反馈，自动调节四腿足端高度（z 方向差动补偿），使机身保持水平。支持：

- 手动开关（`L:1`/`L:0` 绝对值命令，`L:` 裸命令切换）
- Z 标定（各姿态零偏分槽存储）
- 站立/原地抬腿（W 模式）自动激活
- 无倾斜轮式驱动（V 模式 1）自动跟随

## 2. 数据流

```
WT9011G4K (10Hz 上报)
   └─ imu.c 解析 pitch/roll
        └─ AttCtrl_CalibTick()   标定状态机 (5ms, 采样 2s 均值存零偏)
             └─ AttCtrl_LevelUpdate()   自稳解算 (50/100ms)
                  ├─ 低通滤波去抖
                  ├─ 软死区抑制微晃
                  ├─ 比例 + 积分 (消重心偏载常驻残差)
                  └─ 四腿 z 差动输出 (按站高动态限幅)
```

## 3. Z 标定与姿态分槽

不同站姿的 IMU 零偏不同，按姿态分槽存储（5 槽）：

| 槽 | 姿态 | 说明 |
|---|---|---|
| 0 | H（前后不反转，高） | 上电默认低趴并入此槽 |
| 1 | K（前反后不反，高） | |
| 2 | L（前反后不反，低） | |
| 3 | M（前不反后反，低） | |
| 4 | P（前不反后反，高） | |

- `Z` 命令：开始标定（放平地保持静止 2 秒）
- 标定完成后该姿态槽允许开启自稳（未标定姿态 `L:1` 返回错误）

## 4. 控制律

对相对零偏的俯仰/横滚角做处理：

```
flat_p = pitch - offset[pose]      (前倾为正)
flat_r = roll  - roffset[pose]     (右倾为正)

① 低通:  s_lp += alpha * (flat - s_lp)     alpha=0.25 @10Hz ≈ 0.35s 时间常数
② 软死区: |angle| < 0.7° → 0 (无阶跃软过渡)
③ 积分:  s_i += KI * dp, 钳位 pitch ±3° / roll ±6° (仅正常模式)
④ 输出:  pc = (dp + s_i) * rad * 190 (前后髋半距)
         rc = (dr + s_i) * rad * 90  (左右髋半宽)
         dz[FL]=pc-rc  dz[FR]=pc+rc  dz[RL]=-pc-rc  dz[RR]=-pc+rc
⑤ 限幅:  |dz| ≤ 304.6 - stand_h  (按站高动态算伸腿余量)
```

- **软死区**：±0.7° 内不响应（1° 偏粗、0.5° 过敏感，实测折中 0.7°）
- **积分项**：消除重心偏载的常驻残差（纯比例有稳态下垂），抗饱和钳位防发散
- **符号约定**：前倾→前腿伸/后腿收；右倾→右腿伸/左腿收

## 5. 激活条件（主循环判定）

| 场景 | 条件 |
|---|---|
| 站立 | `L:1` 已开 且 非坐/趴/起身/翻转 且 非双腿抬升 |
| 无倾斜驱动 | V 模式 1（LevelAuto 跟随） |
| 原地抬腿（W） | 无条件激活（TROT 且步长为 0），**快速模式** |

## 6. W 快速模式

原地抬腿时对角支撑，机身易翘板，采用快速调平：

| 参数 | 正常模式 | W 快速模式 |
|---|---|---|
| 调用周期 | 100ms | 50ms |
| 低通系数 | 0.25 | 0.50（约 0.1s 时间常数） |
| 死区 | 0.7° | 0.5° |
| 积分 | 启用（钳位 3°/6°） | 禁用（动态快，积分易发散） |

配合重心前移 15mm（W 命令），缓解对角支撑翘板。

## 7. 关键参数汇总

| 参数 | 值 | 说明 |
|---|---|---|
| LV_LPF | 0.25 | 正常低通（10Hz 调用 → 0.35s） |
| LV_LPF_FAST | 0.50 | W 快速低通（50ms 调用 → 0.1s） |
| LV_DEAD | 0.7° | 软死区（正常） |
| LV_DEAD_FAST | 0.5° | 软死区（W 快速） |
| LV_KI | 0.05/tick | 积分系数（约 2s 收敛） |
| LV_I_MAX_P / R | 3° / 6° | 积分抗饱和钳位 |
| LV_HALF_BL / BW | 190 / 90 mm | 前后髋半距 / 左右髋半宽 |
| LV_Z_ROOM_BASE | 304.6mm | 伸腿上限基准（动态限幅用） |

## 8. 已验证效果

- 平地站立：水平保持良好，微晃抑制，重心偏载残差由积分项收敛
- 户外实测：草地/土坡约 10° 坡度站立，机身保持水平
- W 原地抬腿：快速调平 + 重心偏移，翘板明显缓解
- 遥控场景：`L:1/L:0` 绝对值开关保证 APP 与固件状态同步
