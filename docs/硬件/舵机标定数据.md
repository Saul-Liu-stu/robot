# 舵机标定数据

> 四腿自然站立、身体水平时，每个舵机的度数。
> zero_deg：站姿角度，蓝牙调到站稳时的读数。
> dir：角度+10°，和几何正方向一致=1.0，反了=-1.0。

| 关节 | 几何正方向 |
|------|----------|
| 外展 | 腿往外摆 |
| 大腿 | 腿往前摆 |
| 小腿 | 膝弯曲 |
