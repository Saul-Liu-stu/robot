## 二、舵机标定（12 个零点 + dir，实测）

> servo = zero_deg + dir × 几何角
> 零点定义: q1 腿竖直 / q2 大腿竖直 / q3 大小腿成直线

| 腿 | q1 侧摆 | q2 大腿 | q3 小腿 |
|----|---------|---------|---------|
| FL 左前 | 95 / **+1** | 115 / **-1** 🔧 | 93 / **+1** |
| FR 右前 | 94 / **-1** ⚠️ | 150 / **+1** 🔧 | 135 / **-1** |
| RL 左后 | 50 / **-1** | 110 / **-1** | 165 / **+1** |
| RR 右后 | 150 / **+1** ⚠️ | 230 / **+1** | 185 / **-1** 🔧 |

> 🔧 2026-08-16 重装舵机臂（装臂参考角 135° 法），旧值: FL大腿212 / FR大腿65 / RR小腿90。dir 未变。
> ⚠️ 右腿侧摆 dir 经 +10° 实测确认 (FR: 角度<94 往外; RR: 角度>150 往外)。
> 对方仓库里这两处符号相反, 协同合并时以本表为准。

| 参数 | 值 | 说明 |

| step_len | 60 mm (T) / 0 mm (W) | 步幅 / 越障原地抬 |
| step_h | 25 mm (T) / 70 mm (W) | 抬腿（W 越障四腿均满抬，无钳位，极限 88mm） |

| foot_x_shift | 15 mm | 前倾修正（最终实测值，X: 命令可在线调） |

## 四、已知余量（2026-08-16 重装后，X=15）

**低站姿 210mm（四轮驱动，站立不动）：**

| 关节 | 站定舵机角 | 余量 | 备注 |
|------|-----------|------|------|
| RL 小腿 (零165) | 261° | 9° | 全机最紧，限制低站姿不能再矮 |
| 其余 11 舵机 | — | ≥35° | 无钳位 |

**高站姿 280mm（行走，全程扫描）：** 12 舵机全部无钳位，最小余量 ≥35°，RR 抬腿 25mm 满抬。

> 低站姿 210mm 是 RL 小腿余量允许的极限（200mm 只剩 3.8°，标定误差 ±3° 就可能钳位）。
> 低站姿只用于四轮驱动，不要发 T。
