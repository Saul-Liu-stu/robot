## 一、长度测量（卡尺，8 个）

| 腿 | 大腿 L1 | 小腿 L2 | 备注 |
|----|---------|---------|------|
| FL 左前 |130 |180 | 大腿：髋转轴中心→膝转轴中心 |
| FR 右前 |130 |180 | 小腿：膝转轴中心→脚底着地点 |
| RL 左后 |130 |180 | |
| RR 右后 |130 |180 | |

**量法：**

```
大腿 L1: 髋关节转轴的中心点 到 膝关节转轴的中心点，两点直线距离 (mm)

        ● ← 髋转轴中心
       /
      /   ← L1 这段
     /
    ● ← 膝转轴中心
    │
    │  ← L2 这段
    │
    ▼ 脚底着地点（机器人放地上时脚与地面的接触点）
```

> 脚底着地点：机器人正常放地上，从膝转轴中心量到地面接触点。
> 如果脚底是轮子，量到轮子与地面的接触点。

## 二、几何零点（蓝牙扫舵机，8 个）

> 工具：现有蓝牙校准命令 `舵机号:角度` → `Y` 确认。

| 腿 | 大腿零点（舵机号） | 小腿零点（舵机号） |
|----|------------------|------------------|
| FL 左前 | (舵机5)212 | (舵机9)93 |
| FR 右前 | (舵机6) 65| (舵机10)135 |
| RL 左后 | (舵机7) 110| (舵机11)165 |
| RR 右后 | (舵机8) 230| (舵机12) 90|

**大腿零点测法：**

```
调舵机直到大腿完全竖直（与地面垂直）:

    身体 ────────
       │
       │ ← 大腿竖直
       │
       ● 膝
    此时舵机读数 = 大腿零点，记下来
```

**小腿零点测法：**

```
大腿固定不动，调小腿舵机直到大小腿完全成一条直线:

       │
       │ 大腿
       │
       │ 小腿 (和上面同线)
       ●
    此时舵机读数 = 小腿零点，记下来
```

> 注意：零点不一定在 0~270 中间，是多少记多少。
> 测零点时机器人可以侧躺/架空，不用站立。
