# 分步接线与测试指南

> 重新接线用：按 蓝牙 → IMU → 电机驱动 → 舵机 四步走，每步接完立刻测试，通过再进下一步。
> 引脚定义以 [控制板引脚分配表.md](控制板引脚分配表.md) 为准，本文只列本次要接的信号。
> **每步接线前断电，接完检查无误再上电。**

---

## 通用电源规则（重要）

> ⚠️ **你的电源拓扑：主控由电机驱动模块供电** —— TB6612 模块的 5V 输出（板载稳压）接到主控，电机电源 VM 是**全机总开关**：VM 一上电，主控、蓝牙、IMU 跟着才有电。

| 电源 | 供谁 | 上电顺序 |
|------|------|---------|
| 电机电源 VM | TB6612 VM → 模块 5V 输出 → **STM32 + 蓝牙 + IMU** | **最先上**（总开关） |
| 舵机电源 | 3 块舵机驱动板 | **最后上**（舵机电流大，防拉垮主控） |

- **所有 GND 共地**：主控 GND = 蓝牙 GND = IMU GND = 两个 TB6612 GND = 3 块舵机板 GND = 各电源地
- 断电顺序反过来：先断舵机电源，最后断电机电源（主控掉电）
- **阶段 1/2 还没接电机模块时**：主控临时用 USB / 调试器供电测试（或先把 TB6612 模块的电源和 5V→主控接好，提前完成阶段 3 的电源接线）
- 电机电源先上电的瞬间（主控启动前）轮子轻微抖一下正常——MCU 启动后立即接管 STBY

## 阶段 1：蓝牙 HC-05

### 接线

| HC-05 引脚 | 接到 | 说明 |
|-----------|------|------|
| VCC | 5V | 主控 5V |
| GND | 主控 GND | 共地 |
| **TXD** | **PB11** (USART3_RX) | HC-05 发 → STM32 收 |
| **RXD** | **PB10** (USART3_TX) | STM32 发 → HC-05 收 |

### 测试（手机蓝牙串口助手，115200）

| # | 操作 | 预期 |
|---|------|------|
| 1 | 上电 | 收到 `READY`；可能混有 `IMU:NO DATA`（IMU 还没接，正常） |
| 2 | 发 `G` | 回 `STAND...` → `OK:STAND`（舵机没接也不影响回显） |
| 3 | 发 `M0:50:1` | 回 `MA:50:1` |
| 4 | 发 `C` | 回 `PARK` |

**判据**：发什么回什么、不丢字节 → 蓝牙链路 OK，断电进入下一阶段。

## 阶段 2：IMU WT9011G4K

### 接线

| IMU 引脚 | 接到 | 说明 |
|---------|------|------|
| VCC | 5V | |
| GND | 主控 GND | 共地 |
| **TXD** | **PD6** (USART2_RX) | IMU 发 → STM32 收（**唯一必需数据线**） |
| RXD | PD5 (USART2_TX) | 可不接（上电环回自测才用到） |

### 测试

| # | 操作 | 预期 |
|---|------|------|
| 1 | 上电 → 发 `I` | 回 `IMU:ON`；约 1s 后一行 `DBG2:CR1=... raw=N frames=N`（frames 在涨） |
| 2 | 等 2~3 秒 | 每 100ms 一行 `R,x,P,y,Y,z,520`；`IMU:NO DATA` 告警消失 |
| 3 | 手动前倾 IMU | P 值 ÷10 往**正**走；后倾往负 |
| 4 | 左右滚 | R 值变化 |
| 5 | 发 `I` | 回 `IMU:OFF`，数据流停 |
| 6 | **整机断电重启** → 发 `I` | 直接有数据流（**不用重插线**）——验证上电时序自愈 |

**判据**：10Hz 数据流正常、符号方向对、断电重启自愈 → OK，断电进入下一阶段。

## 阶段 3：电机驱动（TB6612 ×2 + 编码器）

### 接线

**2 路模块（Motor A/B = 前轮）**

| TB6612 | 接到 |
|--------|------|
| PWMA | PA8 |
| AIN1 / AIN2 | PE0 / PE1 |
| PWMB | PA9 |
| BIN1 / BIN2 | PE2 / PE3 |
| STBY | PA10 |
| VCC | **5V 输出 → 主控 5V**（板载稳压给全机供电，不要外接 5V） |
| GND | 主控 GND + 电机电源地 |
| VM | 电机电源（总开关） |
| AO1/AO2 | Motor A 两根线（左前轮，正反无所谓） |
| BO1/BO2 | Motor B 两根线（右前轮） |

**4 路模块（Motor C/D = 后轮，只用 CH3/CH4）**

| TB6612 | 接到 |
|--------|------|
| PWMC | PB8 |
| CIN1 / CIN2 | PB5 / PB6 |
| PWMD | PB9 |
| DIN1 / DIN2 | PB7 / PB12 |
| STBY | PA10（与 2 路模块并联） |
| VCC | 两个模块 5V 输出并联后接主控 5V（同源，不要重复外接） |
| GND | 主控 GND + 电机电源地 |
| VM | 电机电源（总开关，可与 2 路模块 VM 并联） |
| CO1/CO2 | Motor C 两根线（左后轮） |
| DO1/DO2 | Motor D 两根线（右后轮） |

**编码器（GMR，在电机轴上）**

| 编码器 | A 相 | B 相 |
|--------|------|------|
| 1（左前） | PE7 | PE8 |
| 2（右前） | PE9 | PE10 |
| 3（左后） | PE11 | PE12 |
| 4（右后） | PE13 | PE14 |

### 测试

| # | 操作 | 预期 |
|---|------|------|
| 1 | 上电 | 上电瞬间可能轻微抖一下，随后四轮静止，无自转 |
| 2 | `M0:50:1` | **只有左前轮转**，转速中等；方向随便（下一条核对） |
| 3 | `M1:50:1` → `M2:50:1` → `M3:50:1` | 依次只有右前 / 左后 / 右后轮转 → 通道映射确认 |
| 4 | `R` | 四轮同向转（前进，30%） |
| 5 | `B` | 四轮反向（后退） |
| 6 | `S` | 全停 |
| 7 | `J` | 回 `J:ON`，之后每 100ms `E,e0,e1,e2,e3,520`；`R` 时四个值一起变正（50% ≈180 RPM 不随 108mm 轮变） |
| 8 | `M0:50:1` | **只有 e0 变** → 通道映射核对；`S` 停 |
| 9 | `J` | 回 `J:OFF` |

**判据**：四个电机通道/方向可控、编码器四通道一一对应 → OK，断电进入下一阶段。
⚠️ 若电机转但 e 值全 0 → 编码器接线/EXTI 问题，修好再往下。

## 阶段 4：舵机（3 块驱动板 + 12 舵机）

### 接线

**模块 A 外展板** → 舵机电源 VCC，GND 共地

| 板通道 | 舵机 | 接到 |
|--------|------|------|
| CH1 | Servo 1（左前外展） | PA0 |
| CH2 | Servo 2（右前外展） | PA7 |
| CH3 | Servo 3（左后外展） | PD15 |
| CH4 | Servo 4（右后外展） | PD14 |

**模块 B 大腿板**

| 板通道 | 舵机 | 接到 |
|--------|------|------|
| CH1 | Servo 5（左前大腿） | PB0 |
| CH2 | Servo 6（右前大腿） | PB1 |
| CH3 | Servo 7（左后大腿） | PD13 |
| CH4 | Servo 8（右后大腿） | PD12 | 

**模块 C 小腿板**

| 板通道 | 舵机 | 接到 |
|--------|------|------|
| CH1 | Servo 9（左前小腿） | PA1 |
| CH2 | Servo 10（右前小腿） | PA2 |
| CH3 | Servo 11（左后小腿） | PA3 |
| CH4 | Servo 12（右后小腿） | PB14 |

**舵机本体**：3 块板每板 4 路信号 + 舵机电源 + GND。舵机编号印在线上或按 [控制板引脚分配表.md](控制板引脚分配表.md) 的映射速查核对。

### 测试

| # | 操作 | 预期 |
|---|------|------|
| 1 | 先上主控电，**再上舵机电源** | 12 舵机无乱动；随后 4 个外展舵机**间隔约 100ms 逐个**锁到 95 / 99 / 50 / 150°（每锁一个能听到"咔"一下） |
| 2 | 校准抽查 | `S1:95` `S2:94` `S3:50` `S4:150` 回显对应值，外展微动/不动 |
| 3 | `G`（机身装好时） | 回 `STAND...` → `OK:STAND`；**扶稳机身**，缓慢站起 280mm 狗姿态，大腿小腿同步到位 |
| 4 | `L` → `K` | 低趴 240 → 升站（慢速约 1.5s），无滋滋堵转 |
| 5 | 姿态矩阵 | `G → K → L → M → P → H → L → K → M → G`，按预期回显 + 动作 |
| 6 | `T` | 四轮 10% 助走 + trot 前进，RR 落点与其余腿对齐（−20mm 修正生效） |
| 7 | `C` → 断电落地 | 慢速贴地趴；断电肚皮再落 ~53mm，听砸落力度 |
| 8 | 上电 → `U` | 回 `RISE`，约 7s 规划站起 |

**判据**：上电外展逐个锁定、姿态矩阵全过、T 行走协调、C/U 正常 → 全部完成。

## 阶段 5：云台舵机（2 路，可选）

### 接线

| 舵机 | 轴 | 信号线 | 电源 |
|------|----|--------|------|
| Gimbal 1 | 水平 pan | **PF8** | 舵机电源（与腿舵机同轨）+ 共地 |
| Gimbal 2 | 俯仰 tilt | **PF9** | 同上 |

> 云台舵机用普通三线舵机线：信号线接 PF8/PF9，正极接舵机电源，地线共地。

### 测试

| # | 操作 | 预期 |
|---|------|------|
| 1 | 上电 | 云台自动回**正对前方**（水平 90 / 俯仰 120） |
| 2 | 发 `G:60:120` | 回 `GM:60,120`；水平右转 30°（<90 往右） |
| 3 | 发 `G:90:75` | 回 `GM:90,75`；俯仰向下 45°（机械限位） |
| 4 | 发 `G:90:180` | 回 `GM:90,180`；俯仰向上到顶 |

**判据**：上电不动、命令后两轴分别对应 pan/tilt 动作 → OK。

## 全部完成后的快速回归（10 分钟）

```
上电 → READY → I(IMU流) → J(编码器流) → G → T → S → G → W → S → G
→ L → R → S → K → C → 断电 → 上电 → U → G
```

任何一步异常：记下命令 + 回显 + 现象，发我。
