# 电机与舵机代码移植文档

> 适用芯片: STM32H743ZIT6 (LQFP144)  
> 驱动: 12路 0-270° 舵机 + 4路 TB6612 直流电机

---

## 一、CubeMX 配置

### 1.1 定时器配置

#### 舵机 PWM（50Hz）

| 定时器 | 通道 | 引脚 | 舵机编号 | Prescaler | Period |
|--------|------|------|----------|-----------|--------|
| **TIM2** | CH1 | PA0 | 舵机1 | 23999 | 199 |
| | CH2 | PA1 | 舵机9 | | |
| | CH3 | PA2 | 舵机10 | | |
| | CH4 | PA3 | 舵机11 | | |
| **TIM3** | CH2 | PA7 | 舵机2 | 23999 | 199 |
| | CH3 | PB0 | 舵机5 | | |
| | CH4 | PB1 | 舵机6 | | |
| **TIM4** | CH1 | PD12 | 舵机8 | 23999 | 199 |
| | CH2 | PD13 | 舵机7 | | |
| | CH3 | PD14 | 舵机4 | | |
| | CH4 | PD15 | 舵机3 | | |
| **TIM12** | CH1 | PB14 | 舵机12 | 23999 | 199 |

> 每个通道均设为 **PWM Generation CHx**，Auto-reload preload = **Enable**

#### 电机 PWM（10kHz）

| 定时器 | 通道 | 引脚 | 电机 | Prescaler | Period |
|--------|------|------|------|-----------|--------|
| **TIM1** | CH1 | PA8 | 电机A | 239 | 99 |
| | CH2 | PA9 | 电机B | | |
| **TIM16** | CH1 | PB8 | 电机C | 239 | 99 |
| **TIM17** | CH1 | PB9 | 电机D | 239 | 99 |

> TIM1 需单独设置 BreakDeadTime 全部 Disable

### 1.2 GPIO 方向引脚

| 引脚 | 标签 | 用途 |
|------|------|------|
| PE0 | AIN1 | 电机A 方向 IN1 |
| PE1 | AIN2 | 电机A 方向 IN2 |
| PE2 | BIN1 | 电机B 方向 IN1 |
| PE3 | BIN2 | 电机B 方向 IN2 |
| PB5 | CIN1 | 电机C 方向 IN1 |
| PB6 | CIN2 | 电机C 方向 IN2 |
| PB7 | DIN1 | 电机D 方向 IN1 |
| PB12 | DIN2 | 电机D 方向 IN2 |
| PA10 | STBY | TB6612 使能（高有效） |

> 全部设为 **GPIO_Output**，推挽输出，无上下拉，低速

### 1.3 CORTEX_M7

无需开 ICache/DCache。若后续需要 Cache，务必先验证 LCD/电机/舵机稳定后单独配置。

## 二、代码移植

### 2.1 需要复制的文件

从原工程复制以下文件到新工程相同路径：

```
Core/Inc/:
  new_servo.h         ← 12舵机 API
  motor_control.h     ← 4电机 API
  leg_config.h        ← 可调参数
  leg_control.h       ← 单腿 API

Core/Src/:
  new_servo.c         ← 12舵机驱动 (0-270°)
  motor_control.c     ← TB6612 4电机驱动
  leg_control.c       ← 单腿控制
```

### 2.2 main.c 修改

#### 2.2.1 添加头文件

```c
/* USER CODE BEGIN Includes */
#include "motor_control.h"
#include "new_servo.h"
#include "leg_control.h"
/* USER CODE END Includes */
```

#### 2.2.2 PWM 启动 + 初始化（在 `/* USER CODE BEGIN 2 */` 内）

```c
/* ==== 4路电机 PWM启动 (10kHz) ==== */
HAL_TIM_PWM_Start(&htim1, TIM_CHANNEL_1);    /* 电机A PA8 */
HAL_TIM_PWM_Start(&htim1, TIM_CHANNEL_2);    /* 电机B PA9 */
HAL_TIM_PWM_Start(&htim16, TIM_CHANNEL_1);   /* 电机C PB8 */
HAL_TIM_PWM_Start(&htim17, TIM_CHANNEL_1);   /* 电机D PB9 */

/* ==== 12路舵机 PWM启动 (50Hz) ==== */
HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_1);    /*  1 PA0 */
HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_2);    /*  9 PA1 */
HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_3);    /* 10 PA2 */
HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_4);    /* 11 PA3 */
HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_2);    /*  2 PA7 */
HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_3);    /*  5 PB0 */
HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_4);    /*  6 PB1 */
HAL_TIM_PWM_Start(&htim4, TIM_CHANNEL_1);    /*  8 PD12 */
HAL_TIM_PWM_Start(&htim4, TIM_CHANNEL_2);    /*  7 PD13 */
HAL_TIM_PWM_Start(&htim4, TIM_CHANNEL_3);    /*  4 PD14 */
HAL_TIM_PWM_Start(&htim4, TIM_CHANNEL_4);    /*  3 PD15 */
HAL_TIM_PWM_Start(&htim12, TIM_CHANNEL_1);   /* 12 PB14 */

/* ==== 电机初始化 + 四足站立 ==== */
Motor_Init();
Leg_Init();
```

## 三、API 速查

### 3.1 舵机 (new_servo)

```c
NewServo_SetAngle(servo_n, angle);   // 单个舵机, angle: 0~270
NewServo_BatchControl(angles);       // 批量12路, angles: uint16_t[12]
```

| 舵机编号 | 引脚 | 腿部位置 |
|----------|------|----------|
| 1 | PA0 | Leg1 外展 |
| 2 | PA7 | Leg2 外展 |
| 3 | PD15 | Leg3 外展 |
| 4 | PD14 | Leg4 外展 |
| 5 | PB0 | Leg1 大腿 |
| 6 | PB1 | Leg2 大腿 |
| 7 | PD13 | Leg3 大腿 |
| 8 | PD12 | Leg4 大腿 |
| 9 | PA1 | Leg1 小腿 |
| 10 | PA2 | Leg2 小腿 |
| 11 | PA3 | Leg3 小腿 |
| 12 | PB14 | Leg4 小腿 |

### 3.2 电机 (motor_control)

```c
Motor_Set(MOTOR_A, speed, dir);   // 电机A, speed: 0~100, dir: 1=正转 0=反转
Motor_Stop(MOTOR_A);              // 停止电机A
Motor_Standby();                  // 全部待机
Motor_Wakeup();                   // 唤醒
```

| 电机 | 编号 | PWM引脚 | 方向引脚 |
|------|------|---------|----------|
| A | MOTOR_A | PA8 | PE0/PE1 |
| B | MOTOR_B | PA9 | PE2/PE3 |
| C | MOTOR_C | PB8 | PB5/PB6 |
| D | MOTOR_D | PB9 | PB7/PB12 |

### 3.3 腿部控制 (leg_control)

```c
Leg_SetJoint(LEG_1, JOINT_ABD,   135);   // 腿1外展
Leg_SetJoint(LEG_1, JOINT_THIGH, 150);   // 腿1大腿
Leg_SetJoint(LEG_1, JOINT_CALF,  120);   // 腿1小腿

Leg_SetPose(LEG_2, 135, 150, 120);       // 腿2三关节

Leg_SetWheel(LEG_3, 80, 1);              // 腿3轮子80%正转

Leg_AllStand();                           // 四足站立
Leg_RaceForward(60);                     // 四轮60%前进
Leg_AllStop();                            // 全部停止
```

### 3.4 参数调优 (leg_config.h)

```c
ABD_ANGLE_STAND   135   // 外展站立角
THIGH_ANGLE_STAND 150   // 大腿站立角
CALF_ANGLE_STAND  120   // 小腿站立角

STAND_POSE[4][3]        // 四条腿各自的站立姿态表

GAIT_CYCLE_MS      800  // 步态周期 ms
```
