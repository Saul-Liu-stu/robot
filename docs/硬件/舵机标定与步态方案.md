## 二、12 舵机标定数据（待测）

> 工具：当前固件的蓝牙校准模式。上电→蓝牙连接→切换舵机→设角度→找站姿。
>
> 操作流程：发 `N` 切到舵机 N → 发角度 + `Y` 确认 → 观察关节位置 → 重复直到找到站姿。

### 标定方法

**zero_deg：** 四腿自然站立时，每个舵机的角度读数。蓝牙 app 发数字找到最佳位置后直接记录。

**dir：** 舵机角度**增大**时，关节往哪个方向运动：

| 关节 | 角度增大 | 机械运动 | 几何正方向 | dir |
|------|---------|---------|----------|-----|
| 外展 | 角度+ | 腿往外摆 / 往内收 | 往外 | 往外=1.0，往内=-1.0 |
| 大腿 | 角度+ | 腿往前摆 / 往后摆 | 往前 | 往前=1.0，往后=-1.0 |
| 小腿 | 角度+ | 膝伸直 / 弯曲 | 弯曲 | 弯曲=1.0，伸直=-1.0 |

测法：当前舵机设一个角度等腿稳定，再+10°，看腿往哪个方向动了。

## 五、从标定到步态的路径

```
你现在在这里
     │
     ▼
┌─────────────────────────┐
│ 1. 用蓝牙校准模式       │
│    测完 12 个 zero_deg  │
│    测完 12 个 dir       │
│    填入 g_leg_calib     │
└──────────┬──────────────┘
           │
           ▼
┌─────────────────────────┐
│ 2. IK 站立验证          │
│    填好校准表后，       │
│    用 IK 算出站姿角度   │
│    写 12 个舵机         │
│    看四腿是否站稳       │
└──────────┬──────────────┘
           │
           ▼
┌─────────────────────────┐
│ 3. 步态运行             │
│    gait.c 调用           │
│    LegIK_SolveServo()    │
│    脚轨迹 → 关节角      │
│    → 舵机 PWM           │
└─────────────────────────┘
```

## 六、当前固件蓝牙协议速查

| 操作 | 发什么 | 收到什么 |
|------|--------|---------|
| 切到舵机 N | `N` | `SW:SN:90` |
| 当前舵机设角度 A | `A` | `SET:SN:A?` |
| 指定舵机设角度 | `N:A` | `SET:SN:A?` |
| 确认 | `Y` | `OK:SN:A` |
| 取消 | `N` | `CANCEL` |
