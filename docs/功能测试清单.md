# 四足机器人功能测试清单 v2.0

> 适用固件：蓝牙协议 v6.5 对应版本。
> 测试方式：手机/PC 蓝牙串口助手（115200）发命令，对照回显 + 观察动作。
> **测试纪律**：每一步都先看回显、再看动作；异常立即 `S`；有任何与预期不符 → 记录现象后继续下一项，最后统一汇报。

---

## 测试前准备（10 分钟）

- [ ] 接线复查：12 舵机、4 电机、IMU（TX→PD6，**115200**）、HC-05（115200）
- [ ] **Clean 后编译烧录**（工程删过/加过文件，必须 Clean）
- [ ] 蓝牙已连，串口助手能看到 `READY`
- [ ] 机器人放**平地**，四周 1m 净空
- [ ] 测试材料：一本 2~3cm 厚的书（越障用）、一块长木板 + 垫高物（做 10° 斜坡用）

## 阶段 C：姿态系统（30 分钟）

### C1 G — 狗高站姿

| 命令 | 预期 |
|------|------|
| `G` | 回 `STAND...` + `OK:STAND`；腿平滑升/降到 280mm 狗姿态（前后正常膝） |
| `L` → `K` | **升站慢速**：约 1.5s 平滑升起（比下降慢，108mm 大轮负载下不卡顿、无滋滋声） |

### C2 K — 前顶高站姿

| 命令 | 预期 |
|------|------|
| `K` | 回 `KNEE` → `FLIP`；前腿足端先往前滚伸直到腿伸直、再收回（约 3s） |
| 目测 | 前腿大腿前摆、**膝盖顶在身体前方**、膝轴离地约 192mm（108mm 轮径基准） |

### C3 L — 前顶低趴

| 命令 | 预期 |
|------|------|
| `L` | 回 `LOW`；**无 FLIP**（同分支直接下降），趴到 191mm |
| 目测 | 四足 ±129.5 对称展开，**大腿≈平行地面、小腿垂直地面**（视觉姿态），膝高(几何) 180mm（实际离地再 +54mm），四轮着地 |

### C4 P — 后顶高站姿

| 命令 | 预期 |
|------|------|
| `P` | 回 `REARH` → `FLIP`；前后腿**同时**翻膝（约 3s），升到 280 |
| 目测 | 后腿大腿前摆、膝盖顶在身体前下方 |

### C5 M — 后顶低趴

| 命令 | 预期 |
|------|------|
| `M` | 回 `REAR`；**无 FLIP**，直接趴到 240 |
| 目测 | 前腿狗腿、后腿膝盖收进车身下，四膝离地 |

### C6 切换矩阵（全组合走一遍）

按序执行，每步确认站高/膝分支：

```
G → K → L → M → P → H → L → K → M → G
```

**规律**：K↔L、M↔P 无 FLIP（直接升降）；其余组合先 `FLIP`（约 3s）再升降；任何切换膝不磕地、轮不侧铲。

### C7 翻膝专项观察

- [ ] `FLIP` 回显在按下约 0.8s 后出现，总时长约 3s
- [ ] 全程膝离地 ≥110mm（低趴态除外）
- [ ] 翻完后自动继续升降

### C10 站立自稳（2026-08-23 新增，H/K 高站姿）

前置：平地、`G` 或 `K` 站姿（放平地并扶稳）。

| 命令 | 预期 |
|------|------|
| `L:1`（未标定） | 回 `LV:NOCAL`，腿不动 |
| `Z` → 等 2s | 回 `CAL:OK`（自稳零偏已存） |
| `L:1` | 回 `LV:ON`，平地上腿不动（零偏正确） |
| 前轮下垫 **30mm** 木块 | ~1s 内前腿伸长/后腿缩短，身体自动回平（4.5° 倾角） |
| 前轮下垫 **50mm** | 身体回平（7.5°，接近前腿伸直极限）；再垫高身体保留剩余倾斜、不崩 |
| 右侧两轮垫 **40mm** | 右腿伸长/左腿缩短，身体回平（滚转 12.5°）；**若方向相反 → 记录并反馈（roll 符号待实测）** |
| 垫块撤走 | 身体回平（dz 归零） |
| `T` 行走中 | 自稳不叠加（步态正常）；`S` 停后回站立自动恢复自稳 |
| `C` → `U` | 收纳/站起过程中自稳不叠加，站起完成后恢复 |
| `K` 姿态重复垫块测试 | 前顶高站姿同样回平（需先 `Z` 标定 K） |
| `L:0` | 回 `LV:OFF`，身体停在当前姿态不再修正 |
| `W` 用过后发 `L:0` | 总开关：W 残留的自稳跟随也一并关闭（腿不再自动调平，直到再发 L:1 或 S/经典V） |
| 重启 | 自稳开关回默认关（不记忆） |
| 平地轻推机身（<1° 晃动） | 腿**不动**（±1° 死区生效）；手压机身 >2° 才响应 |
| 垫 30mm 块后回平 | 回平过程无过冲震荡（死区不引入阶跃） |

### C11 V 模式1 无倾斜驱动（2026-08-23 新增，第二套轮盘）

前置：平地、`G` 高站姿、`Z` 标定过 H。

| 命令 | 预期 |
|------|------|
| `V:30:0:1` | 四轮前进 30%；**起步不低头**（无倾斜补偿）；回平后身体水平 |
| `V:0:30:1` | 原地右转；**不压弯**（无侧倾补偿） |
| 行驶中前轮上小坡/过坎 | 身体自动保持水平（自稳跟随，和站立自稳同效果） |
| `V:-30:0:1` | 后退，同样无倾斜 |
| `V:0:0:1` | 渐停，身体保持水平（自稳仍在） |
| `V:30:0`（无第三参） | 回经典模式：起步**有**低头倾斜补偿 |
| `K` 姿态下发 `V:30:0:1` | 回 `FLIP` 自动翻回 H（约 3s），翻完前轮子不动；翻完继续前进 |
| `L` 低趴下发 `V:30:0:1` | 同上：先翻膝回 H 再走 |
| `S` 停止后发 `V:30:0:1` | 直接走（H 已是正常膝，无 FLIP） |
| 未 `Z` 标定发 `V:30:0:1` | 正常驱动，但自稳不生效（腿不动）；标定后恢复 |
| `H:230` | 回 `HIGH:230`；从 280 平滑蹲到 230（~1s 渐变） |
| `H:230` 后前轮垫高 70mm（≈10.5°） | 自稳回平（280 站高做不到 10.5°，230 站高 23° 以内可回平） |
| `H:230` 下 `V:20:0:1` 上真坡（≤23°） | 车身全程保持水平；若坡 >23° 身体保留剩余倾斜（钳位不崩） |
| 行驶中发 `H:230` | 边滚边平滑蹲下，自稳不掉线 |
| 回平地发 `H` | 平滑站回 280，回 `HIGH` |
| `H:100`（非法值） | 回 `HIGH:230`（落缺省 230） |

| `N:1:1`（右前） | 抬起时**支撑腿自动左移**（重心转移 15mm），机身不往右倒——重点验证 |
| `N:0:0` | 回 `LG:0,0`；1.2s 慢慢放下，足端停在前伸位着地（不回原位） |
| `N:1:1` 抬起中 → `N:2:1` | 回 `LG:BUSY`（互斥：FR 在空中） |
| `N:1:1` → `N:1:0` 落地后 → `N:2:1` | **不 BUSY**：FR 落地即释放，RL 立即能抬（前伸记忆模式） |
| 四腿依次抬放一轮 | 四足全部前伸 80mm 姿态（身体不位移）；期间每腿落地后即可抬下一条 |
| 前伸的腿再按抬（`N:0:1` 第二次） | 原地抬起（不追加前伸，80mm 上限） |
| 四腿前伸后发 `G` | 四足全部滚回站立位（前伸记忆清零） |
| 抬起中立即 `N:1:0` | 中途转放下，无跳变（平滑反向） |
| `N:3:1`（右后） | 右后腿抬起 50×80（后腿舵机余量验证） |
| `L:1` 开着，前轮垫 30mm + `N:0:1` | 抬 FL 过程中其余三腿自稳调平，机身保持水平 |
| `N:2:1` 悬空时发 `V:15:0:1` | 其余三轮行进，空中的 RL 保持悬空，机身自稳 |

| 悬空时发 `G` | 空中腿立即收回站立位 |
| `T` 行走中发 `N:0:1` | 回 `LG:NO`（trot 不可用） |
| 裸 `N` | 仍是舵机校准退出（`CANCEL`），与 N: 不冲突 |

### I6.9 上台阶双腿抬（N:4/N:5，2026-08-25 新增）

前置：`G` 高站姿；平地先测。

| 命令 | 预期 |
|------|------|
| `N:4:1` | 回 `LG:4,1`；前双腿 50mm 直抬，**两条腿同时抬起**，到位悬空保持 |

## 阶段 K：收纳与站起（15 分钟）

| 步骤 | 命令 | 预期 |
|------|------|------|
| 收纳 | `G` 站好后 → `C` | 回 `PARK`；**慢速缓降约 2~3s** 到 72mm 贴地趴：四腿伸直外展 ±297、膝高约 67mm、肚皮离地约 **53mm**（108mm 大轮抬高车身） |
| 断电落地 | **断电** | 肚皮再落 ~53mm（落差比旧轮大 21.5mm），**重点听砸落力度**；轮子保持外伸，无关节折进身下 |
| 上电 | 上电（不发命令） | 外展锁定不扭腿（q1≈0 兼容）；大腿/小腿松弛 |
| 规划站起 | `U`（上电后**直接可用**，不再 NOT PARK） | 回 `RISE`；**指令角先同步趴姿**（不上扫腿）→ 单段 3.5s **先顶升后收腿**到前顶低趴 191（低处足端保持外伸，随站高上升收拢）+ **重心渐向左后挪**（卸载 FR）→ 完成回 `LOW`，**无翻膝**；全程缓慢、无磕碰、**前后腿动作对称、FR 不堵转、身体不往右前倾** |
| 兜底站起 | 再 `C` → 断电 → 上电 → `G` | G 强起（力矩大，仅记录现象对比） |
| 边界 | 非收纳状态发 `U` | 回 `NOT PARK`，不动作 |
| 大轮落地 | `C` 后目测 | 肚皮离地约 53mm；四轮应已着地（收纳全程轮子贴地滚动） |
| 大轮间隙 | `L`/`M` → `W` 抬腿 / `D:2:30` 压弯 | 108mm 大轮不蹭车身、不干涉腿（新轮径重点检查） |

> 关键观察：趴下速度是否均匀缓慢；断电后肚皮落差是否明显变小；U 站起全程是否顺滑。
