# 四足机器人功能测试清单 v2.0

> 适用固件：蓝牙协议 v6.3 对应版本。
> 测试方式：手机/PC 蓝牙串口助手（115200）发命令，对照回显 + 观察动作。
> **测试纪律**：每一步都先看回显、再看动作；异常立即 `S`；有任何与预期不符 → 记录现象后继续下一项，最后统一汇报。

---

## 测试前准备（10 分钟）

- [ ] 接线复查：12 舵机、4 电机、IMU（TX→PD6，**115200**）、HC-05（115200）
- [ ] **Clean 后编译烧录**（工程删过/加过文件，必须 Clean）
- [ ] 蓝牙已连，串口助手能看到 `READY`
- [ ] 机器人放**平地**，四周 1m 净空
- [ ] 测试材料：一本 2~3cm 厚的书（越障用）、一块长木板 + 垫高物（做 10° 斜坡用）

---

## 阶段 A：上电自检（5 分钟，不发任何命令）

| 步骤 | 预期 |
|------|------|
| 上电瞬间 | 12 舵机无乱动 |
| 随后 | 4 个外展舵机**间隔约 100ms 逐个**锁到 95 / 94 / 50 / 150° |
| 大腿/小腿 | 松弛可手掰 |
| 串口 | 收到 `READY`；**无** IMU 数据流（I 默认关） |
| 电机 | 不转 |

---

## 阶段 B：IMU 上报（10 分钟）

| 步骤 | 命令 | 预期回显/现象 |
|------|------|--------------|
| 开启上报 | `I` | `IMU:ON`，随后每 100ms 一行 `R,x,P,y,Y,z,520`（如 `R,-12,P,34,Y,1579,520`） |
| 诊断行 | 按 `I` 后等 1 秒 | 一行 `DBG2:CR1=... raw=N frames=N` |
| 平放读数 | — | P 值 ÷10 ≈ 0±3° |
| 手动前倾 | — | P 值往**正**走 |
| 手动后倾 | — | P 值往**负**走 |
| 左右滚 | — | R 值变化 |
| 关闭上报 | `I` | `IMU:OFF`，数据流停 |
| 上电时序验证 | IMU 线**保持接好** → 整机断电重启 → `I` | 直接有数据流（不需要重插线）——验证 ErrorCallback+看门狗双保险 |
| 断线告警 | 拔 IMU 线 | 约 5s 后每 2s 一行 `IMU:NO DATA raw=N frames=N`；插回自动恢复 |

## 阶段 C：姿态系统（30 分钟）

### C1 G — 狗高站姿

| 命令 | 预期 |
|------|------|
| `G` | 回 `STAND...` + `OK:STAND`；腿平滑升/降到 280mm 狗姿态（前后正常膝） |

### C2 K — 前顶高站姿

| 命令 | 预期 |
|------|------|
| `K` | 回 `KNEE` → `FLIP`；前腿足端先往前滚伸直到腿伸直、再收回（约 3s） |
| 目测 | 前腿大腿前摆、**膝盖顶在身体前方**、膝轴离地约 171mm |

### C3 L — 前顶低趴

| 命令 | 预期 |
|------|------|
| `L` | 回 `LOW`；**无 FLIP**（同分支直接下降），趴到 220mm |
| 目测 | 前后足 ±120 对称展开，四膝离地 ≥180mm，四轮着地 |

### C4 P — 后顶高站姿

| 命令 | 预期 |
|------|------|
| `P` | 回 `REARH` → `FLIP`；前后腿**同时**翻膝（约 3s），升到 280 |
| 目测 | 后腿大腿前摆、膝盖顶在身体前下方 |

### C5 M — 后顶低趴

| 命令 | 预期 |
|------|------|
| `M` | 回 `REAR`；**无 FLIP**，直接趴到 220 |
| 目测 | 前腿狗腿、后腿膝盖收进车身下，四膝离地 |

### C6 切换矩阵（全组合走一遍）

按序执行，每步确认站高/膝分支：

```
G → K → L → M → P → H → L → K → M → G
```

**规律**：K↔L、M↔P 无 FLIP（直接升降）；其余组合先 `FLIP`（约 3s）再升降；任何切换膝不磕地、轮不侧铲。

### C7 翻膝专项观察

- [ ] `FLIP` 回显在按下约 0.8s 后出现，总时长约 3s
- [ ] 全程膝离地 ≥110mm（低趴态除外）
- [ ] 翻完后自动继续升降

## 阶段 D：步态（20 分钟）

### D1 T — 连续 Trot

| 命令 | 预期 |
|------|------|
| `G` → `T` | 回 `TROT`；平滑渐入后持续走（1.2s/周期、步幅 60mm），**无左右摇摆**，直线前进 |
| `G` | 平滑回站姿停住 |

### D2 A — 单步调试

| 命令 | 预期 |
|------|------|
| `G` → `A`×4 | 回 `PH:0` → `PH:90` → `PH:180` → `PH:270`，每次停在对应相位 |

### D3 W — 越障模式

| 命令 | 预期 |
|------|------|
| 地面放 2~3cm 书 → `W` | 回 `CLIMB`；四轮 30% 前进 + 对角交替抬腿 70mm，跨过障碍 |
| `S` → `G` | 停轮、腿回站姿 |
| 边界：`L` → `W` | 自动先 `FLIP` 回正常膝再开走 |

### D4 E — 转圈动作

| 命令 | 预期 |
|------|------|
| `G` → `E` | 回 `SWAY:1`；顺时针原地转圈 |
| `E:0` | 回 `SWAY:-1`；逆时针，速度相当 |
| `G` | 停止 |

### D5 边界记录（无需修）

| 命令 | 现象（记录即可） |
|------|-----------------|
| `L` → `T` | 低趴行走，小腿可能钳位、动作怪异——属预期外用法，正式使用先 `G` |

## 阶段 E：轮式控制（10 分钟）

| 命令 | 预期回显/现象 |
|------|--------------|
| `G` → `R` | `ROLL`，四轮 30% 前进直线 |
| `B` | `BACK`，后退 |
| `S` | `STOP`，立即全停 |
| `M0:50:1` | `MA:50:1`，电机 A 50% 正转 |
| `M0:0` | `MA:0:1`，电机 A 停 |
| `M2:100` | `MC:100:1`，电机 C 100% 正转（方向缺省验证） |
| **`M` 单独发** | `REAR` 并执行后顶低趴（**姿态命令不被吞**——M 冲突修复验证） |
| `G` | 回狗高站姿 |
| `L` → `R` → `G` | 滚动中切姿态：轮子不停（G 不碰电机），腿平滑升起——正常行为 |

---

## 阶段 F：坡度自适应（20 分钟）

| 步骤 | 命令 | 预期 |
|------|------|------|
| 标定 | 平地站好 → `Z` | 回 `CALIB...`；**2 秒内保持完全静止** → 回 `SLOPE:ON` |
| 再按 `Z` | `Z` | 回 `SLOPE:OFF`（关闭） |
| 开启并上坡 | `Z`（标定）→ `R` 冲上 10° 坡 | 上坡约 2~3s 后：足端整体**后移**（身体前压），车身与坡面平行、不后仰 |
| 回到平地 | 继续 `R` | 约 2~3s 后足端恢复原位 |
| 反复上下坡 | — | 坡顶附近不来回抖（迟滞 2° 生效） |
| 调参 | `Q:1:6` / `Q:3:5` 等 | 回 `AT:OK`，重测观察效果 |

坡度参数默认值：`Q:0:0.002`（低通）、`Q:1:5`（上坡阈值°）、`Q:2:2`（迟滞°）、`Q:3:3.5`（力度 mm/°）、`Q:4:40`（后移上限 mm）。**最终值发回写死。**

## 阶段 H：异常边界抽查（10 分钟）

- [ ] 翻膝进行中（`FLIP` 后 3s 内）按 `G`：翻膝继续、完成后按新目标执行，无乱动作
- [ ] 翻膝进行中按 `S`：电机停，腿部不受影响
- [ ] 发未知命令（如 `V`）：回 `UNK:V`
- [ ] 任何动作出现"滋滋"堵转声 → 立即 `S` 断电，记下是哪个关节
