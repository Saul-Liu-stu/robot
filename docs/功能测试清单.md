# 四足机器人功能测试清单 v2.0

> 适用固件：蓝牙协议 v6.5 对应版本。
> 测试方式：手机/PC 蓝牙串口助手（115200）发命令，对照回显 + 观察动作。
> **测试纪律**：每一步都先看回显、再看动作；异常立即 `S`；有任何与预期不符 → 记录现象后继续下一项，最后统一汇报。

---

## 测试前准备（10 分钟）

- [ ] 接线复查：12 舵机、4 电机、IMU（TX→PD6，**115200**）、HC-05（115200）
- [ ] **Clean 后编译烧录**（工程删过/加过文件，必须 Clean）
- [ ] 蓝牙已连，串口助手能看到 `READY`
- [ ] 机器人放**平地**，四周 1m 净空
- [ ] 测试材料：一本 2~3cm 厚的书（越障用）、一块长木板 + 垫高物（做 10° 斜坡用）

## 阶段 A：上电自检（5 分钟，不发任何命令）

| 步骤 | 预期 |
|------|------|
| 上电瞬间 | 12 舵机无乱动 |
| 随后 | 4 个外展舵机**间隔约 100ms 逐个**锁到 95 / 94 / 50 / 150° |
| 大腿/小腿 | 松弛可手掰 |
| 串口 | 收到 `READY`；**无** IMU 数据流（I 默认关） |
| 电机 | 不转 |

## 阶段 B：IMU 上报（10 分钟）

| 步骤 | 命令 | 预期回显/现象 |
|------|------|--------------|
| 开启上报 | `I` | `IMU:ON`，随后每 100ms 一行 `R,x,P,y,Y,z,520`（如 `R,-12,P,34,Y,1579,520`） |
| 诊断行 | 按 `I` 后等 1 秒 | 一行 `DBG2:CR1=... raw=N frames=N` |
| 平放读数 | — | P 值 ÷10 ≈ 0±3° |
| 手动前倾 | — | P 值往**正**走 |
| 手动后倾 | — | P 值往**负**走 |
| 左右滚 | — | R 值变化 |
| 关闭上报 | `I` | `IMU:OFF`，数据流停 |
| 上电时序验证 | IMU 线**保持接好** → 整机断电重启 → `I` | 直接有数据流（不需要重插线）——验证 ErrorCallback+看门狗双保险 |
| 断线告警 | 拔 IMU 线 | 约 5s 后每 2s 一行 `IMU:NO DATA raw=N frames=N`；插回自动恢复 |

## 阶段 C：姿态系统（30 分钟）

### C1 G — 狗高站姿

| 命令 | 预期 |
|------|------|
| `G` | 回 `STAND...` + `OK:STAND`；腿平滑升/降到 280mm 狗姿态（前后正常膝） |

### C2 K — 前顶高站姿

| 命令 | 预期 |
|------|------|
| `K` | 回 `KNEE` → `FLIP`；前腿足端先往前滚伸直到腿伸直、再收回（约 3s） |
| 目测 | 前腿大腿前摆、**膝盖顶在身体前方**、膝轴离地约 171mm |

### C3 L — 前顶低趴

| 命令 | 预期 |
|------|------|
| `L` | 回 `LOW`；**无 FLIP**（同分支直接下降），趴到 220mm |
| 目测 | 前后足 ±120 对称展开，四膝离地 ≥180mm，四轮着地 |

### C4 P — 后顶高站姿

| 命令 | 预期 |
|------|------|
| `P` | 回 `REARH` → `FLIP`；前后腿**同时**翻膝（约 3s），升到 280 |
| 目测 | 后腿大腿前摆、膝盖顶在身体前下方 |

### C5 M — 后顶低趴

| 命令 | 预期 |
|------|------|
| `M` | 回 `REAR`；**无 FLIP**，直接趴到 220 |
| 目测 | 前腿狗腿、后腿膝盖收进车身下，四膝离地 |

### C6 切换矩阵（全组合走一遍）

按序执行，每步确认站高/膝分支：

```
G → K → L → M → P → H → L → K → M → G
```

**规律**：K↔L、M↔P 无 FLIP（直接升降）；其余组合先 `FLIP`（约 3s）再升降；任何切换膝不磕地、轮不侧铲。

### C7 翻膝专项观察

- [ ] `FLIP` 回显在按下约 0.8s 后出现，总时长约 3s
- [ ] 全程膝离地 ≥110mm（低趴态除外）
- [ ] 翻完后自动继续升降

## 阶段 D：步态（20 分钟）

### D1 T — 连续 Trot

| 命令 | 预期 |
|------|------|
| `G` → `T` | 回 `TROT`；平滑渐入后持续走（1.2s/周期、步幅 60mm），**无左右摇摆**，直线前进 |
| `G` | 平滑回站姿停住 |

### D2 A — 单步调试

| 命令 | 预期 |
|------|------|
| `G` → `A`×4 | 回 `PH:0` → `PH:90` → `PH:180` → `PH:270`，每次停在对应相位 |

### D3 W — 越障模式

| 命令 | 预期 |
|------|------|
| 地面放 2~3cm 书 → `W` | 回 `CLIMB`；四轮 30% 前进 + 对角交替抬腿 70mm，跨过障碍 |
| `S` → `G` | 停轮、腿回站姿 |
| 边界：`L` → `W` | 自动先 `FLIP` 回正常膝再开走 |

### D4 E — 转圈动作

| 命令 | 预期 |
|------|------|
| `G` → `E` | 回 `SWAY:1`；顺时针原地转圈 |
| `E:0` | 回 `SWAY:-1`；逆时针，速度相当 |
| `G` | 停止 |

### D5 边界记录（无需修）

| 命令 | 现象（记录即可） |
|------|-----------------|
| `L` → `T` | 低趴行走，小腿可能钳位、动作怪异——属预期外用法，正式使用先 `G` |

## 阶段 E：轮式控制（10 分钟）

| 命令 | 预期回显/现象 |
|------|--------------|
| `G` → `R` | `ROLL`，四轮 30% 前进直线 |
| `B` | `BACK`，后退 |
| `S` | `STOP`，立即全停 |
| `M0:50:1` | `MA:50:1`，电机 A 50% 正转 |
| `M0:0` | `MA:0:1`，电机 A 停 |
| `M2:100` | `MC:100:1`，电机 C 100% 正转（方向缺省验证） |
| **`M` 单独发** | `REAR` 并执行后顶低趴（**姿态命令不被吞**——M 冲突修复验证） |
| `G` | 回狗高站姿 |
| `L` → `R` → `G` | 滚动中切姿态：轮子不停（G 不碰电机），腿平滑升起——正常行为 |

## 阶段 F：坡度自适应（20 分钟）

| 步骤 | 命令 | 预期 |
|------|------|------|
| 标定 | 平地站好 → `Z` | 回 `CALIB...`；**2 秒内保持完全静止** → 回 `SLOPE:ON` |
| 再按 `Z` | `Z` | 回 `SLOPE:OFF`（关闭） |
| 开启并上坡 | `Z`（标定）→ `R` 冲上 10° 坡 | 上坡约 2~3s 后：足端整体**后移**（身体前压），车身与坡面平行、不后仰 |
| 回到平地 | 继续 `R` | 约 2~3s 后足端恢复原位 |
| 反复上下坡 | — | 坡顶附近不来回抖（迟滞 2° 生效） |
| 调参 | `Q:1:6` / `Q:3:5` 等 | 回 `AT:OK`，重测观察效果 |

坡度参数默认值：`Q:0:0.002`（低通）、`Q:1:5`（上坡阈值°）、`Q:2:2`（迟滞°）、`Q:3:3.5`（力度 mm/°）、`Q:4:40`（后移上限 mm）。**最终值发回写死。**

## 阶段 I：摇杆驱动与倾斜平衡（30 分钟，新功能）

> 先测编码器（I1），编码器通了再测倾斜（I2~I5）——倾斜的"到速回平"依赖编码器平台期判定。

### I1 编码器转速上报

| 步骤 | 命令 | 预期 |
|------|------|------|
| 开启 | `J` | 回 `J:ON`，之后每 100ms 一行 `E,e0,e1,e2,e3,520`（静止时全 0） |
| 四轮正转 | `R` | 四个值一起变正，约 **108 RPM**（30% 占空比 × 满速 360） |
| 停 | `S` | 归零 |
| 四轮反转 | `B` | 四个值一起变负 |
| 停 | `S` | 归零 |
| 单轮核对 | `M0:50:1` | **只有 e0 变**，约 **180 RPM**（实测） |
| | `M1:50:1` / `M2:50:1` / `M3:50:1` | 分别只有 e1 / e2 / e3 变 → 通道映射确认 |
| 关闭 | `J` | 回 `J:OFF` |

> ⚠️ 若电机转动但数值全 0 → 编码器没通（CubeMX EXTI 配置/接线问题），**先修好再往下测**。

### I2 V 前进 + 起步低头

| 步骤 | 命令 | 预期 |
|------|------|------|
| 站好 | `G` | 狗高站姿 |
| 起步 | `V:30:0` | **无回显**（正常）；约 0.3s 渐快至 30% 占空比直线前进（V 值=占空比%，1:1）；起步瞬间平台**低头**（前低后高，最多约 4.5°） |
| 到速 | 保持 `V:30:0` | 速度稳定后约 0.3s 内平台**自动回平** |
| 持续 | — | 匀速直线前进，车身平稳 |

### I3 V 渐停 + 刹车抬头

| 步骤 | 命令 | 预期 |
|------|------|------|
| 减速 | `V:0:0` | 约 0.5s 内渐停（不是急刹）；减速期间平台**抬头**（前高后低）；停稳后完全回平 |

### I4 V 后退

| 步骤 | 命令 | 预期 |
|------|------|------|
| 后退 | `V:-20:0` | 后退；起步**抬头**补偿（车身前栽的反向补偿）；`V:0:0` 渐停 |

### I5 转弯压弯

| 步骤 | 命令 | 预期 |
|------|------|------|
| 原地右转 | `V:0:40` | 原地右转（俯视顺时针）+ 平台**右倾**（左低右高，最多约 2.7°）；`V:0:0` 停 + 回平 |
| 原地左转 | `V:0:-40` | 对称：左转 + 左倾 |
| 混合 | `V:30:15` | 前进 + 右转，边转边压弯 |
| 回中 | `V:0:0` | 渐停回平 |

### I6 方向核对（重点，不对就报告）

- [ ] `V:30:0` 是**前进**（不是后退）
- [ ] `V:0:40` 是**右转**（俯视顺时针，不是左转）
- [ ] 若方向反 → 记录现象，改一行代码即可

### I7 交互边界

| 场景 | 预期 |
|------|------|
| V 行驶中按 `S` | 立即停 + 回平（急停，不走斜坡） |
| V 行驶中按 `R` | R 接管（30% 前进），倾斜归零 |
| V 行驶中按 `G` | 腿回站姿，轮子继续滚（G 不碰电机，正常行为） |
| `L` 低趴下发 `V:30:0` | 低趴姿态摇杆驱动，坡度层同时生效（上坡仍会前压） |

### I8 手感调优（测试后把感觉发我）

| 感觉 | 改哪个 |
|------|--------|
| 起步太猛/太肉 | 斜坡速率（当前 0.5s 到满速） |
| 倾斜太大/太小 | k_pitch（当前 15mm 满量程） |
| 压弯太大/太小 | k_roll（当前 10mm 满量程） |
| 倾斜收放太突兀 | tilt_slew（当前 300ms 过渡） |

## 阶段 J：方向按键（20 分钟，固定倾斜版）

| 步骤 | 命令 | 预期 |
|------|------|------|
| 前进 | `D:0:30` | 回 `DRV:0:30`；30% 占空比前进，**全程保持低头 10mm**（不到速回平） |
| 停止 | `S` | 急停 + **立即回平**（这是唯一回平时机） |
| 后退 | `D:1:30` | 后退，**全程保持抬头 10mm** |
| 停止 | `S` | 回平 |
| 左前 | `D:2:30` | 前进+左弧线（左轮约4%/右轮约40%，弧线明显），**左边低**（左倾 10mm + 低头 6mm）全程保持 |
| 右前 | `D:3:30` | 前进+右弧线，**右边低**（右倾 10mm）全程保持 |
| 停止 | `S` | 回平 |
| 覆盖关系 | `D:0:30` → `V:30:0` → `D:3:30` | V 与 D 互斥，谁最后按下谁接管（摇杆代码保留） |

> 注意：D 按键的倾斜**不到速回平**——行驶全程保持，`S` 才平。与 V 的"到速自动回平"是两种行为，按需用。

## 阶段 K：收纳与站起（15 分钟）

| 步骤 | 命令 | 预期 |
|------|------|------|
| 收纳 | `G` 站好后 → `C` | 回 `PARK`；**慢速缓降约 2~3s** 到 72mm 贴地趴：四腿伸直外展 ±297、膝高约 67mm、肚皮离地约 32mm |
| 断电落地 | **断电** | 肚皮只再落 ~32mm，**无砸落声**；轮子保持外伸，无关节折进身下 |
| 上电 | 上电（不发命令） | 外展锁定不扭腿（q1≈0 兼容）；大腿/小腿松弛 |
| 规划站起 | `U`（上电后**直接可用**，不再 NOT PARK） | 回 `RISE`；阶段A（3.5s）收腿+缓升到 240 → 回 `FLIP` → 阶段B 翻膝升 280（共约 7s）；全程缓慢、无磕碰、无滋滋堵转声 |
| 兜底站起 | 再 `C` → 断电 → 上电 → `G` | G 强起（力矩大，仅记录现象对比） |
| 边界 | 非收纳状态发 `U` | 回 `NOT PARK`，不动作 |

> 关键观察：趴下速度是否均匀缓慢；断电后肚皮落差是否明显变小；U 站起全程是否顺滑。
