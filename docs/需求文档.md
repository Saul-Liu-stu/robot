|---|---|

| 文档版本 | V1.0 |
| 编制日期 | 2026 年 8 月 10 日 |
| 编制人 | 项目团队 |

## 1. 项目背景

野外探测与救援任务中，废墟、山地、草地/土坡等复杂环境对移动平台提出苛刻要求：传统轮式平台通过性不足，纯四足平台平地效率低、控制复杂。本项目在电赛 QuadArm 原型基础上迭代，定位为**低成本的轮腿混合移动平台**——平地轮式高效移动，崎岖地形步态行走，并以 IMU 姿态自稳与主动越障能力支撑野外环境作业，为探测与救援类应用提供平台基础。

## 2. 目标与范围

- **目标**：以不超过 2000 元整机成本，实现轮腿双模移动、姿态自稳、主动越障与云台视觉四项核心能力，完成样机验证；
- **范围**：机器人本体（结构、硬件、固件）+ QT 蓝牙控制端（遥控 + 视觉检测）；
- **不包含**：自主导航、机械臂操作、远距通信（预留迭代空间）。

## 3. 功能需求

| 编号 | 需求描述 | 优先级 |
|---|---|---|
| FR-1 | 轮式移动：前进、后退、左转、右转、原地自转，四轮独立驱动 | 高 |
| FR-2 | 步态移动：对角步态（TROT），步长、步高、站高、站姿宽度参数化可调 | 高 |
| FR-3 | 站姿切换：高/低站姿切换与前倾修正 | 高 |
| FR-4 | 站起/趴下：站起机动（趴姿→站姿路径规划） | 中 |
| FR-5 | 姿态自稳：IMU 反馈四腿 z 差动补偿，倾斜地面机体保持水平（Z 标定 + 开关控制） | 高 |
| FR-6 | 主动越障：原地抬腿（对角支撑）；台阶辅助抬升（双腿同步直抬，与轮滚协同） | 高 |
| FR-7 | 云台与图传：二自由度云台指向控制，摄像头画面图传回传 | 中 |
| FR-8 | 上位机视觉：QT 端颜色检测与运动检测 | 中 |
| FR-9 | 遥控：按键遥控页（四向控制、速度档、站姿宽度调节），蓝牙串口协议全指令文档化 | 高 |
| FR-10 | 在线调参：全部运动参数支持在线修改，无需重新烧录 | 高 |

## 4. 性能需求

| 编号 | 指标 | 目标值 |
|---|---|---|
| PR-1 | 站高 | 210~280mm 在线可调（常用站姿 230mm） |
| PR-2 | 主动抬腿高度 | ≥50mm |
| PR-3 | 台阶通过 | 6~7cm |
| PR-4 | 坡面通过 | ≥10° |
| PR-5 | 轮式速度 | ≥1.5 m/s（轮毂直径 11cm，电机最高 300rpm） |
| PR-6 | 续航 | ≥1h（3S 2550mAh ×2） |
| PR-7 | 整机重量 | ≤1.5kg |
| PR-8 | 姿态自稳 | 死区 0.7°，稳态残差收敛（积分项消除） |
| PR-9 | 姿态反馈 | IMU 10Hz（俯仰/横滚） |
| PR-10 | 整机成本 | ≤2000 元 |

## 5. 可靠性需求

| 编号 | 需求描述 |
|---|---|
| RR-1 | IWDG 独立看门狗：异常卡死自动复位 |
| RR-2 | 舵机行程余量校验：所有姿态执行前校验行程可行性 |
| RR-3 | 姿态标定：各站姿 IMU 零偏分槽存储，上电可标定（Z 命令） |
| RR-4 | 抬腿高度受舵机行程约束保护（≤50mm） |

## 6. 设计约束

- 硬件平台：STM32H743 主控 + 12×270° 舵机 + 4×MG513 轮电机（TB6612）+ WT9011G4K IMU + 4×GMR 编码器 + 2×180° 云台舵机 + HC-05 蓝牙；
- 团队规模：3 人；开发周期：2026 年 8 月（约一个月集中开发）；
- 成本上限：2000 元；
- 通信：蓝牙串口（近距离遥控，远距通信为后续迭代方向）。

## 7. 验收对照

需求验收以《功能测试清单》逐项回归为准（姿态控制 / 步态 / 越障 / 遥控四类场景），全部核心场景通过即视为需求达成，遗留低优先级改进项记录于开发日志问题追踪表。
