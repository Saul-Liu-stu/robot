## 1. 项目快照

- **项目**：四足轮腿机器人，STM32H743ZITx @480MHz，D-Cache 开（MPU Region1 = 0x24000000 非缓存，512KB 对齐）
- **结构**：12 路舵机（三块舵机板，TIM2/TIM3/TIM4/TIM12/TIM16/TIM17 输出）+ 4 轮电机（TB6612×2，TIM1/TIM8 PWM）+ IMU（WT9011G4K，USART2，**115200**）+ HC-05 蓝牙（USART3，115200，TX 用 DMA）
- **开发模式**：CubeMX 生成骨架，业务代码全部在 USER CODE 区；与 partner（GitHub lemonlgt/dog）协同但各自独立开发
- **编译验证手段**（本机无 ARM 工具链）：
  ```bash
  gcc -fsyntax-only -DSTM32H743xx -DUSE_HAL_DRIVER -ICore/Inc \
    -IDrivers/STM32H7xx_HAL_Driver/Inc -IDrivers/STM32H7xx_HAL_Driver/Inc/Legacy \
    -IDrivers/CMSIS/Device/ST/STM32H7xx/Include -IDrivers/CMSIS/Include -IHardware <file>
  ```

## 2. 当前固件功能总表（全部已实现）

| 命令 | 功能 |
|------|------|
| `G`/`H` | 狗高站姿 280mm（前后正常膝；反折膝先翻膝再升），两者等价 |
| `K` | 前顶高站姿 280（前腿反折膝） |
| `L` | 前顶低趴 220（前后足 ±120 展开，四轮驱动用） |
| `P` | 后顶高站姿 280（后腿反折膝） |
| `M` | 后顶低趴 220（注意：第二字节是数字时放行给电机命令） |
| 翻膝机动 | 姿态切换自动执行：足端伸到直腿点（两膝分支连续处）翻转分支再收回，约 3s，回显 `FLIP`，前后腿组按 mask 独立翻 |
| `T` | 纯 trot（步幅 60/抬腿 25/周期 1.2s/duty 0.6，无横移） |
| `E`/`E:0` | 转圈动作（trot + 重心横移定死 15mm，顺/逆时针） |
| `W` | 越障模式（四轮 30% + 高站姿 280 + 对角抬腿 70mm；反折膝先翻膝） |
| `A` | 单步调试（相位 0/90/180/270） |
| `F` | 横移走（已暂停，代码保留） |
| `R`/`B`/`S` | 四轮前进/后退/停（R 置位轮式模式，坡度层生效） |
| `M0:50:1` | 电机单控（A/B 方向已在驱动层纠正） |
| `X:±60` | 前倾修正（默认 15mm） |
| `I` | IMU 上报开关：10Hz `R,x,P,y,Y,z,520`（角度×10 定点整数） |
| `Z` | 坡度功能：当前姿态标定 2s + 开启；再按关闭（每姿态单独存零偏，5 槽） |
| `Q:i:v` | 坡度参数在线调（0=lpf_alpha, 1=up_thr, 2=hyst, 3=gain, 4=shift_max） |
| 校准命令 | `1~12`/`角度`/`舵机:角度`/`Y`/`N`（启用中，#if 1） |

6. M 姿态与 M0:50:1 电机命令冲突已修复（姿态分支看第二字节）
7. UART4（PC10/PC11）由用户 CubeMX 新增，保留备用未使用
8. 编码器 ENC3/4 的 EXTI15_10 处理器被 CubeMX 重生成删除——查证原本就是死代码（NVIC 从未使能、固件无调用），**用户决定长期不管**

## 6. 已知遗留 / 注意事项

- 编码器功能停用（用户决定长期不用）
- F 横移走暂停（实测效果不佳），代码保留在 walk_gait.c（FootTargetLat）
- 低趴 220 时勿发 T（会钳位），文档已标注
- 姿态切换时 R 滚动中的轮子不会被 G/T 停止（正常行为）
- 上电默认低趴与 H 共用坡度零偏槽 0（姿态切换后建议重新 Z 标定）
- 舵机校准命令当前启用（#if 1），用户重装舵机臂后需改回 #if 0
- M 姿态命令解析顺序：在电机 M 命令之前，但第二字节为数字时跳过姿态分支
- 所有命令回显必须**单发**（ISR 中连发 DMA 会死锁——排错记坑 #4）
