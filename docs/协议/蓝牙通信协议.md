|------|------|------|
| `R` | **一键滚动** — 四电机 30% 正转 | `ROLL` |
| `B` | **一键后退** — 四电机 30% 反转 | `BACK` |
| `S` | **一键停** — 四电机全停 | `STOP` |

- A/B 电机的方向已在驱动层纠正（接线相反），命令语义统一

| 编号 | 关节 |
|------|------|
| 1~4 | 外展（FL / FR / RL / RR） |
| 5~8 | 大腿（FL / FR / RL / RR） |

|------|------|------|

## IMU 姿态上报（上行数据流，I 命令开关）

- 发 `I` 开启、再发 `I` 关闭，开启后 **10Hz** 固定频率（与模块输出率一致）
- 格式（参考 adc_10 多参数采集系统风格，全整数传输）：

```
R,<roll_x10>,P,<pitch_x10>,Y,<yaw_x10>,520\r\n
例: R,-12,P,34,Y,1579,520
```

| 字段 | 含义 | 说明 |
|------|------|------|
| R | 横滚 roll | 整数 = 角度×10（0.1° 分辨率，-12 = -1.2°） |
| P | 俯仰 pitch | 同上；**前倾为正、后倾为负**（实测约定） |
| Y | 偏航 yaw | 同上（Z 轴漂移，不可长期参考） |
| 520 | 帧尾 | 校验标记，末字段非 `520` 的帧丢弃 |

- 帧类型判定：逗号分割后 7 个字段且末字段为 `520` → IMU 帧
- IMU 模块：WT9011G4K，115200bps，TX → PD6(USART2_RX)
- 上报与命令回显交错出现，上位机按帧尾/前缀分发解析

## 编码器转速上报（上行数据流，J 命令开关）

- 发 `J` 开启、再发 `J` 关闭，开启后 **10Hz** 固定频率

```
E,<rpm0>,<rpm1>,<rpm2>,<rpm3>,520\r\n    例: E,0,150,0,-150,520
```

| 字段 | 含义 | 说明 |
|------|------|------|
| E | 帧标识 | 编码器转速帧 |
| rpm0~3 | 电机 A/B/C/D 输出轴转速 | 整数 RPM（带符号：正=正转），满速约 ±360（实测 50% 占空比 ≈180） |
| 520 | 帧尾 | 校验标记 |

- 转速由四路 GMR 编码器 EXTI 计数换算（100ms 采样窗口）
- 用途：① 调试显示 ② 倾斜平衡的"到速平台期"判定（固件内部使用）

## 上电状态

1. 12 路舵机 PWM 全开（CCR=0 无脉冲）
2. **外展 4 舵机**（1~4）100ms 错开锁到站姿角：95 / 94 / 50 / 150°
3. 大腿/小腿 8 舵机保持松弛（指令角已预置为 IK 站姿解，首次 G 不跳变）
4. **电机 PWM 启动但 CCR=0**，STBY 拉高待命，不转
5. 蓝牙发 `READY\r\n` 自检
6. 模式 = CALIB（5ms 控制循环不碰舵机），等命令

## 步态说明（3D IK + walk_gait）

```
5ms 控制节拍 (200Hz):
  模式机: CALIB(不动) / STAND(站立) / TROT(行走) / STEP(单步冻结)

  STAND: 足端目标 = 前移修正 + 低趴外伸(站高越低前后腿越外伸)
         → 3D IK(前后腿膝分支独立: 正常/反折) → 12舵机
  TROT:  足端轨迹(支撑60%: 贴地+30→-30mm; 摆动40%: 椭圆抬25mm)
         → 3D IK → 12舵机
         E 转圈时额外叠加重心横移 ±15mm (E:0 反向)
  STEP:  同上但行走时刻冻结, A 每次 +1/4 周期

  指数平滑: 指令角 += (目标-指令角)×速率(站0.12/走0.20) → 批量写12路
```

参数（walk_gait.c 的 g_walk_params，运行时可改）：

| 参数 | 值 |
|------|-----|
| step_len 步幅 | 60mm（T 行走）/ 0mm（W 越障原地抬）/ 30mm（F 横移，已暂停） |
| step_h 抬腿 | 25mm（T 行走）/ 70mm（W 越障）/ 40mm（F 横移，已暂停） |
| period 周期 | 1.2s |
| duty 支撑比 | 0.6 |
| stand_h 站高 | 280mm（默认，G/H/K/P 高姿态）/ 240mm（M 后顶低趴）/ 191mm（L 前顶低趴，四轮驱动） |
| foot_x_shift 前移修正 | 15mm（最终实测默认值），X: 命令仍可在线调，正值修正前倾 |
| y_shift 重心横移 | 15mm（定死，仅 E 转圈动作用），E:0 取反为逆时针 |

## 典型操作流程

### 调试步态

```
G  →  站立（平滑渐进）
A  →  相位0 (支撑起始)            PH:0
A  →  相位1/4 (FL+RR抬腿)         PH:90
A  →  相位1/2 (对角交换)          PH:180
A  →  相位3/4 (FR+RL抬腿)         PH:270
A  →  循环
G  →  平滑回站姿
```

### 连续行走

```
G  →  站立
T  →  相位从0起, 平滑渐入 → 连续 Trot (1.2s/周期, 步幅60mm)
G  →  平滑回站姿
```

### 五姿态切换（H / K / L / M / P）

```
H  →  狗姿态高站姿 280mm (前后腿正常膝)  → HIGH → 配 T 行走 / W 越障
K  →  前顶高站姿 280mm (前腿反折 + 后腿正常) → KNEE
L  →  低趴 191mm = K 姿态趴下 (前反折, 四足±129.5对称, 大腿≈水平+小腿垂直) → LOW → 配 R/B/S 车轮跑
M  →  低趴 240mm = 后顶版 (前腿狗腿正常 + 后腿反折膝往前突, 重心集中) → REAR
P  →  后顶高站姿 280mm = M 的高姿态版 → REARH
```

**翻膝机动**（切换时自动执行，指定腿组）：

```
需要翻的腿组足端沿地面伸到直腿点(此点两膝分支连续) → 翻转分支 → 收回到站姿点
前腿往+伸, 后腿往-伸; 回显 FLIP, 膝离地全程 ≥110mm, 总时长约 3s
```

- K↔L、M↔P 同分支，直接升降，无翻膝；其余组合自动识别需翻的前/后腿组
- 上电默认狗姿态（前后正常膝，站高 280），G = 狗高站姿（等价于按 H）
- ⚠️ 低趴 240mm（L/M）只用于四轮驱动，不要发 T。要走路先按 G 或 H。

### 前倾修正

```
身体前倾(重心偏前) → 抬前脚被压/拖地
X:10  →  足端前移 10mm, 观察身体是否回正    XSH:10
X:20  →  不够再加大                          XSH:20
X:-10 →  反了就往回调                        XSH:-10
```

- 站立/行走同时生效，行走中也可实时调
- 调好后把默认值写进 `g_walk_params.foot_x_shift` 即可永久生效

### 轮式滚动

```
R  →  四电机 30% 正转 → 往前滚
B  →  四电机 30% 反转 → 往后退
S  →  四电机全停（急停）
M1:60:0  →  单电机B 60% 反转（单独调试）
```

> 轮径 108mm（2026-08-20 更换，旧 65mm）：同占空比实际车速约 +67%（50% ≈ 180 RPM ≈ 1.0 m/s）。
> 编码器在电机输出轴上，转速读数不随轮径变（50% 仍 ≈180 RPM）。
> 站立姿态实际车身高度 = stand_h + 轮半径（代码无轮径补偿，240 → 实际 294mm）。
```

### 越障模式（W）

```
W  →  原地对角抬腿 50mm, 高站姿 280mm, **不动轮**
      (FL+RR 与 FR+RL 两组交替: 摆动相抬起→落下, 足端不前后移)
      → 配合 V:速度:转向:1 (无倾斜轮盘) 边抬腿边前进
      → 自稳自动跟随 (先 Z 标定): 支撑腿 z 补偿, 防对角支撑翘板
        (无自稳时重心偏一侧会把摆动腿压回地面, 只剩对侧腿抬着)
        W 模式为快速档: 50ms 更新 + 快速低通(~0.1s) + 死区0.5° + 舵机跟随2倍速
      → 重心横移补偿: 足端整体右移=身体左移 (默认 15mm, 补偿机身右侧偏重)
        调参: W:毫米 (范围 ±40, 如 W:25 加重左移; 还往右倾就加大)
        (对角支撑时绕支撑线的倾倒是静态不可控的, 重心必须摆到对角线上)

### W 越障抬腿（APP 侧约定）

- **W 按钮**：发 `W` 进入越障抬腿（回 `CLIMB`）；重复发 `W` 会重置相位（相当于重新开始）
- **重心补偿滑块**（建议放在 W 按钮旁边）：
  - 范围 **0~40**，默认 **15**，显示"重心左移补偿 mm"
  - 拖动中/松手时发 `W:毫米`，固件回 `WCOM:毫米`（APP 用回显刷新显示，不要等 WCOM 之外的状态）
  - **W 运行中发 `W:毫米` 只改补偿量**：不重置相位、不停轮，可实时观察效果
- 退出越障抬腿：发 `G`（回站姿）或 `T`（转行走）；停轮保持抬腿：`S`
- 调参口诀：机身往右倾/往右转 → 滑块加大；往左倾 → 减小；调到满意把数值反馈给固件方写死默认
S  →  只停电机, 腿继续抬 → 要停腿再发 G (G 同时停轮)
G  →  腿回站姿
T  →  退出越障回纯行走 (恢复步幅60/抬腿25)
```

### 云台控制（G:）

```
G:90:120  →  水平90° + 俯仰120° (正对前方) → 回显 GM:90,120
G:90      →  只转水平, 俯仰保持当前值
上电默认  →  90/120 正对前方 (实测确认)

水平 pan:  0~180°;  90=正对前方, <90 往右转, >90 往左转
俯仰 tilt: 75~180°; 120=正对前方, <120 往下(机械限位 75°), >120 往上
           (固件自动限幅: 超出范围按边界值)
分辨率约 9°/档
```

- 云台舵机: 180° 数字舵机 ×2, TIM13 CH1(PF8)=水平 pan, TIM14 CH1(PF9)=俯仰 tilt, 50Hz
- **上电自动回正对前方 (90/120)**
- 任何模式下都可用（与行走/站姿互不干扰）；`G` 不带冒号仍是站姿命令

### 轮盘控制约定（APP 侧）

- 轮盘**无回中**：拖到哪云台停在哪（固件不做回中，松手不动作）
- APP 拖动轮盘时以 ~10Hz 发 `G:水平:俯仰`；每次把两轴当前值一起发（只发一轴时另一轴保持）
- 方向映射（轮盘→角度）：
  - 水平轮盘右拨 → 角度**减小**（<90 往右）；左拨 → 增大
  - 俯仰轮盘下拨 → 角度**减小**（<120 往下）；上拨 → 增大（注意 75 下限，APP 侧同样把轮盘滑到头钳在 75）

### 转圈动作（E）

```
E    →  trot + 重心横移15mm, 顺时针原地转圈    SWAY:1
E:0  →  横移取反, 逆时针原地转圈               SWAY:-1
G    →  回站姿停止转圈
```

### 坡度自适应（已删除）

> 2026-08-23 从固件删除（未实测、与站立自稳职责重叠）。能力由站立自稳 + V 模式1 覆盖。

### 站立自稳（H/K 高站姿）

```
Z    →  放平地保持当前姿态静止2秒 → 标定 pitch/roll 零偏 → CAL:OK
L:1  →  开启自稳 (LV:ON; 当前姿态未标定时回 LV:NOCAL)
      →  站立静止时: 身体往哪边倾, 哪边腿伸长撑回水平 (10Hz, 低通约0.6s)
L:0  →  关闭 (LV:OFF), 总开关: 同时清 W/V模式1 的自稳跟随残留
```

- 适用姿态：仅 **H（狗高）** 与 **K（前顶高）** 280mm（P 后顶站 RR 大腿余量 7° 不启用）
- 单腿 z 补偿上限**按当前站高动态算**：`304.6 − 站高`（280≈25mm→7.5°坡、**230≈75mm→23°坡**、220≈85mm→26.5°坡、210≈95mm→30°坡）；超出后钳位，身体保留剩余倾斜
- **爬陡坡流程**：平地 `G` → `Z` 标定 → `V:..:1` 接近坡底 → `H:230` 边开边蹲（~1s 平滑）→ 上坡保持水平（≤23°）→ 回平地 `H` 站起
- **死区 ±1°**（2026-08-23）：微小晃动不响应，软死区无阶跃
- 生效条件：站立静止（行走 T/W/E、站起 U、翻膝、收纳 C、坐姿 O 中不叠加）**或 V 模式1 无倾斜驱动中**（自动跟随，无需 L:1，需先 Z 标定 H）
- 零偏按姿态分存（H/K 各标一次），`Z` 重复按可重新标定覆盖
- roll 符号待实测：右倾 = roll 正（若方向反了改固件一个符号）

### 摇杆遥控（APP 第四页，V 命令）

**APP 端逻辑（供 APP 开发参考）：**

```
摇杆上下: 前进/后退 → V:sp:st 的 sp 分量 (-50~+50)
摇杆左右: 左转/右转 → V:sp:st 的 st 分量 (-50~+50)
发送频率: 握住摇杆时每 50~100ms 发一次 (建议 100ms)
摇杆回中: 发 V:0:0 (固件自动渐停+回平)
姿态按钮: 直接发 G/H/K/L/M/P (现有命令)
V 命令无回显: APP 不要等应答, 状态显示用 IMU/编码器流
```

**固件行为：**

```
V:30:0   → 四轮 30% 占空比前进 (0.5s 斜坡渐入, 1:1 映射)
V:-20:0  → 四轮 20% 占空比后退
V:0:40   → 原地右转 (左轮正转/右轮反转, 各40%)
V:30:15  → 前进 + 右转 (左45% / 右15% 差速)
V:0:0    → 渐停 (带刹车抬头补偿), 0.5s 内停稳
S        → 急停 (立即停 + 回平)
速度换算: V 值 = 占空比% (1:1), 满速 V:50 ≈ 180 RPM (3.6 RPM/单位)
```

**模式 1（无倾斜补偿移动轮盘，`V:sp:st:1`）：**

```
V:30:0:1   → 无倾斜补偿前进 30% + 高站姿280 + 自稳保持平台水平
V:0:30:1   → 原地右转, 无压弯
行为:
- 无倾斜平衡: 起步不低头/不压弯, 身体水平完全交给 IMU 自稳层
- 高站姿: 当前反折膝时先自动翻膝回 H (回 FLIP), 翻完前驱动命令忽略; 正常膝时**按当前站高行驶**（配合 `H:230` 蹲低爬陡坡, 不强制 280）
- 自稳自动跟随: 不需先发 L:1, 但 H 姿态必须先 Z 标定过 (未标定则只驱动不自稳)
- 高频流不回显, APP 不要等应答
- 退出: 回模式0 (V:0:0 两参) 或 S/姿态命令
```

### 倾斜平衡（V 摇杆 + D 方向按键）

**V 摇杆（随加速过程动态收放）：**

| 场景 | 补偿动作 | 幅度 |
|------|---------|------|
| 起步加速（前进） | 平台主动**低头**（前腿 z 缩短/后腿 z 伸长） | ∝(命令−实际占空比)，上限 15mm ≈ 4.5° |
| 起步加速（后退） | 平台主动**抬头**（车身前栽的反向补偿） | 同上反向 |
| 刹车减速 | 平台主动**抬头**（前进刹车）/ **低头**（后退刹车） | 同上 |
| 左转/右转 | 平台向弯内**压弯**（左转左边低、右转右边低） | ∝转向量，上限 10mm ≈ 2.7° |
| 到速 | 编码器转速**平台期**判定（300ms 窗口增量 <2 RPM）→ 提前回平 | 0.3s 渐变 |
| 兜底 | 占空比斜坡完成 → 倾斜自动归零；编码器无信号时靠此兜底 | — |

**D 方向按键（固定倾斜，全程保持）：**

| 方向 | 轮速 | 固定倾斜 |
|------|------|---------|
| `D:0` 前进 | spd 前进 | 低头 10mm 保持 |
| `D:1` 后退 | spd 后退 | 抬头 10mm 保持 |
| `D:2` 左前 | 前向 3/4 + 左转 3/5（弧线明显） | 低头 6mm + **左倾 10mm（左边低）** 保持 |
| `D:3` 右前 | 前向 3/4 + 右转 3/5 | 低头 6mm + **右倾 10mm（右边低）** 保持 |

- **只有停止（`S`）才回平**，行驶全程保持倾斜（与 V 的到速回平行为不同）
- **切换动作时先回平再倾斜**：换方向（如左前→右前）或从摇杆切到按键时，平台先回平（约 0.2s），到位后再压新方向（约 0.2s），动作分两段，不直接横摆
- 倾斜只在轮式驱动（V/D/R）下生效，`S` 立即回平
- 过渡速率 0.25mm/5ms（约 300ms），起步不猛
- V 与 D 互斥：谁最后按下谁接管；摇杆代码保留

### 收纳与站起（C / U）

```
C  →  慢速缓降 (约2~3s) 到 72mm 贴地趴:
      四腿伸直外展 (前+297/后-297), 膝高约67mm, 肚皮离地约53mm
      → 断电: 肚皮再落 ~53mm (108mm大轮抬高车身, 落差变大需实测砸落力度)
上电 → 外展锁定角度与贴地趴兼容 (q1≈0), 不会扭腿
U  →  规划式站起 (回显 RISE → 完成回 LOW, 上电后直接可用):
      单段 (3.5s): 先顶升后收腿 → 前顶低趴 191mm (与趴姿同膝分支, 免翻膝)
      足端沿 大腿(q2±90)+小腿(q3) 双边界内收 (低站高时腿只能近伸直外伸,
      收拢量随站高上升逐步放开, 低力矩)
      + 重心挪移: h>100mm 后重心渐移向左后角(RL) 15/10mm, 卸载右前腿(FR)
      完成后 = 前顶低趴姿态: 直接发 R 四轮驱动, 或 G/K 再升到高站姿
```

> 收纳姿态下勿发 T；断电前先按 C；上电站起用 U（G 也可强起，但力矩大，仅兜底）。

```
F     →  自动切狗姿态280 + 四腿外展横向扫步 + 原地抬腿40mm, 身体向右
F:0   →  向左横着走
G     →  腿回站姿停止横移
```

## 调试回显

| 上行 | 含义 |
|------|------|
| `UNK:xxx\r\n` | 固件收到无法识别的命令，原样回显（排查用） |
| `READY\r\n` | 上电自检（TX/DMA 通道正常） |
| `FLIP\r\n` | 翻膝机动开始（H/K/L/M/P 姿态切换中需翻膝时自动触发，约 3s 完成） |
| `CALIB...` / `CAL:OK` | 自稳标定：开始 / 完成（零偏已存，可开自稳） |
| `IMU:ON` / `IMU:OFF` | IMU 上报开关回显 |
| `R,x,P,y,Y,z,520` | IMU 角度帧，I 开启后 10Hz（见"IMU 姿态上报"节） |
| `J:ON` / `J:OFF` | 编码器转速上报开关回显 |
| `E,e0,e1,e2,e3,520` | 编码器转速帧，J 开启后 10Hz（见"编码器转速上报"节） |
| `DBG2:CR1=... ISR=...` | I 按下后的 USART2 寄存器 + 收发计数诊断（排查接收链用） |
| `IMU:NO DATA raw=N frames=N` | I 开启但 5s 无有效帧的告警（每 2s 一次，排查接收链用） |
| `SIT` | 坐姿命令回显（O，后腿需翻膝时先回 `FLIP`） |
| `TROTB` | 倒着走回显（T:-1） |
| `GM:pan,tilt` | 云台角度设置回显（G:水平:俯仰） |
| `WCOM:毫米` | W 重心补偿量回显（W:毫米 命令，APP 滑块用） |

### 状态栏显示方案（纯 APP 侧，回显驱动）

- APP 维护一个"当前姿态 + 当前行为"状态，**每次收到回显就更新**，不需要问机器人
- 蓝牙刚连上时状态未知 → 显示"未同步"，发一条 `G` 或等第一条回显后刷新（或引导用户按 G）

| 收到的回显 | 姿态栏 | 行为栏 |
|-----------|--------|--------|
| `READY` | （上电初始） | 校准模式 |
| `STAND...` → `OK:STAND` | 狗高 280 | 站立 |
| `HIGH` | 狗高 280 | 站立 |
| `KNEE` | 前顶高 280 | 站立 |
| `REARH` | 后顶高 280 | 站立 |

| `TROTB` | — | 倒着走 |
| `RISE` | — | 规划站起中（约 7s） |

### 方向显示（实时，APP 自算，无需固件配合）

页面中央可做一个方向指示（箭头/文字），**由 APP 自己的操作状态实时计算**——APP 发什么命令，箭头就显示什么：

| APP 当前操作 | 方向显示 |
|-------------|---------|
| 摇杆 sp>0, st=0 | 前进 |
| 摇杆 sp<0, st=0 | 后退 |
| 摇杆 sp=0, st>0 | 原地右转 |
| 摇杆 sp=0, st<0 | 原地左转 |
| 摇杆 sp>0, st>0 | 右前 |
| 摇杆 sp>0, st<0 | 左前 |
| 摇杆 sp<0, st>0 | 右后 |
| 摇杆 sp<0, st<0 | 左后 |
| 摇杆回中 / 无操作 | 停止 |
| 按钮 `R` / `B` | 前进 30% / 后退 30% |
| 按钮 `T` / `W` | 行走前进 / 越障前进 |
| 按钮 `E` / `E:0` | 顺时针转圈 / 逆时针转圈 |

- 摇杆方向随摇杆实时变（10Hz 发命令的同时刷新箭头），松手显示"停止"
- **实际方向核对**（可选）：轮式模式下用 `J` 流的 RPM 符号交叉验证——四轮同正=实际在前进、同负=后退、左正右负=右转、左负右正=左转

### 数据区显示（配合 I / J 流）

| 显示项 | 数据源 | 解析 |
|--------|--------|------|
| 横滚/俯仰/偏航 | `I` 流 `R,x,P,y,Y,z,520` | ÷10 = 角度，P 正=前倾 |
| 四轮转速 | `J` 流 `E,e0,e1,e2,e3,520` | 直接显示 RPM（正=正转） |

### 交互提醒

- 摇杆驾驶前先确保姿态就位（低趴 L/M 是四轮驱动姿态，狗高 G 也能开）
- 行走按钮（T/W/E）只在狗高姿态用；低趴下发 T 会钳位（APP 可把 T/W/E 置灰直到收到 `STAND`/`HIGH` 回显）
- 急停永远可用：`S` 立即停轮
