## 全部命令速查

### 步态控制（3D IK + walk_gait 版）

| 命令 | 效果 | 应答 |
|------|------|------|
| `G` | **站立** — 3D IK 解算站姿（当前高度），5ms 平滑循环渐进 | `STAND...` → `OK:STAND` |
| `H` | **高站姿** — 站高切到 280mm 并站立（抬腿明显） | `HIGH` |
| `L` | **低站姿** — 站高切到 240mm 并站立（狗形深蹲） | `LOW` |
| `X:20` | **前倾修正** — 足端前移 20mm（身体后坐），站立/行走同时生效，`X:-10` 反向 | `XSH:20` |
| `A` | **单步调试** — 首次进相位0，之后每次 +1/4 周期，平滑过渡后停住 | `PH:0` / `PH:90` / `PH:180` / `PH:270` |
| `T` | **连续 Trot** — 相位从0开始，平滑渐入后持续走 | `TROT` |

### 电机控制

| 命令 | 效果 | 应答 |
|------|------|------|
| `R` | **一键滚动** — 四电机 30% 正转 | `ROLL` |
| `S` | **一键停** — 四电机全停 | `STOP` |
| `M0:50:1` | 电机A 50%占空比 正转 | `MA:50:1` |
| `M1:30:0` | 电机B 30% 反转 | `MB:30:0` |
| `M2:100` | 电机C 100% 正转（方向缺省=正转） | `MC:100:1` |
| `M0:0` | 电机A 停止 | `MA:0:1` |

- 电机号 `0~3` = A/B/C/D
- 速度 `0~100`（0 = 停止）
- 方向 `1`=正转, `0`=反转, 可省略
- A/B 电机的方向已在驱动层纠正（接线相反），命令语义统一

### 舵机校准（已启用，重装舵机臂后标定用；标定完可改回 `#if 0`）

舵机编号映射：

| 编号 | 关节 |
|------|------|
| 1~4 | 外展（FL / FR / RL / RR） |
| 5~8 | 大腿（FL / FR / RL / RR） |
| 9~12 | 小腿（FL / FR / RL / RR） |

| 命令 | 效果 | 应答 |
|------|------|------|
| `1`~`12` | 切换校准舵机号 | `SW:S3` |
| `角度` | 当前舵机设角度，需确认 | `SET:S3:150?` |
| `舵机:角度` | 指定舵机设角度，需确认 | `SET:S3:150?` |
| `Y` | 确认执行 | `OK:S3:150` |
| `N` | 取消 | `CANCEL` |

> ⚠️ 校准必须在上电后直接进行（CALIB 模式）。一旦发过 `G/T/H/L`，5ms 控制循环会持续写全部舵机，手动指令会被覆盖。若要恢复校准，重新上电。

> dir 不需要重测：只转动舵机臂重新对零只影响 `zero_deg`，dir 由舵机本体安装朝向决定。若舵机本体朝向也变了，需用 +10° 法重测 dir。

## 上电状态

1. 12 路舵机 PWM 全开（CCR=0 无脉冲）
2. **外展 4 舵机**（1~4）100ms 错开锁到站姿角：95 / 94 / 50 / 150°
3. 大腿/小腿 8 舵机保持松弛（指令角已预置为 IK 站姿解，首次 G 不跳变）
4. **电机 PWM 启动但 CCR=0**，STBY 拉高待命，不转
5. 蓝牙发 `READY\r\n` 自检
6. 模式 = CALIB（5ms 控制循环不碰舵机），等命令

## 步态说明（3D IK + walk_gait）

```
5ms 控制节拍 (200Hz):
  模式机: CALIB(不动) / STAND(站立) / TROT(行走) / STEP(单步冻结)

  STAND: 足端目标 = 髋正下方 (0, ±10, 当前站高) → 3D IK → 12舵机
  TROT:  足端轨迹(支撑60%: 贴地+30→-30mm; 摆动40%: 椭圆抬25mm)
         → 3D IK → 12舵机
  STEP:  同上但行走时刻冻结, A 每次 +1/4 周期

  指数平滑: 指令角 += (目标-指令角)×速率(站0.12/走0.20) → 批量写12路
```

参数（walk_gait.c 的 g_walk_params，运行时可改）：

| 参数 | 值 |
|------|-----|
| step_len 步幅 | 60mm |
| step_h 抬腿 | 25mm（低站姿时 RR 小腿会钳位，已接受） |
| period 周期 | 1.2s |
| duty 支撑比 | 0.6 |
| stand_h 站高 | 240mm（低）/ 280mm（高），H/L 切换 |
| foot_x_shift 前移修正 | 15mm（最终实测默认值），X: 命令仍可在线调，正值修正前倾 |

## 典型操作流程

### 调试步态

```
G  →  站立（平滑渐进）
A  →  相位0 (支撑起始)            PH:0
A  →  相位1/4 (FL+RR抬腿)         PH:90
A  →  相位1/2 (对角交换)          PH:180
A  →  相位3/4 (FR+RL抬腿)         PH:270
A  →  循环
G  →  平滑回站姿
```

### 连续行走

```
G  →  站立
T  →  相位从0起, 平滑渐入 → 连续 Trot (1.2s/周期, 步幅60mm)
G  →  平滑回站姿
```

### 高低站姿切换

```
L  →  低站姿 240mm (狗形深蹲) → LOW
H  →  高站姿 280mm (抬腿明显) → HIGH
T  →  以当前高度行走
```

### 前倾修正

```
身体前倾(重心偏前) → 抬前脚被压/拖地
X:10  →  足端前移 10mm, 观察身体是否回正    XSH:10
X:20  →  不够再加大                          XSH:20
X:-10 →  反了就往回调                        XSH:-10
```

- 站立/行走同时生效，行走中也可实时调
- 调好后把默认值写进 `g_walk_params.foot_x_shift` 即可永久生效

### 轮式滚动

```
R  →  四电机 30% 正转 → 往前滚
S  →  四电机全停（急停）
M1:60:0  →  单电机B 60% 反转（单独调试）
```

### 校准舵机（已启用，上电后、发 G/T 前使用）

```
5        →  SW:S5
150      →  SET:S5:150?
Y        →  OK:S5:150
```

## 电流保护

| 动作 | 保护 |
|------|------|
| 上电外展锁定 | 4 舵机 100ms 错开 |
| 所有模式切换 | 指数平滑渐进（每拍只逼近目标的 12~20%） |
| 连续 Trot | 每拍角度变化微小，无需额外处理 |

| 上行 | 含义 |
|------|------|
| `UNK:xxx\r\n` | 固件收到无法识别的命令，原样回显（排查用） |
| `READY\r\n` | 上电自检（TX/DMA 通道正常） |

## 已知兼容性注意

- STM32H7 D-Cache：TX 前刷缓存（`SCB_CleanDCache_by_Addr`），SRAM 缓冲区不回旧数据
- MPU Region 1 必须是 512KB 对齐的 `0x24000000`（整个 D1 RAM 非缓存）
