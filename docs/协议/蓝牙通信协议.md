# 蓝牙通信协议 v3.0

> HC-05 SPP | 115200 bps | TX: DMA | RX: 中断 | 无握手

---

## 传输层

| 参数 | 值 |
|------|-----|
| 模块 | HC-05 经典蓝牙 SPP |
| 波特率 | 115200 bps |
| 数据/校验/停止 | 8 / None / 1 |
| 引脚 | PB10(TX) / PB11(RX) |
| Android UUID | `00001101-0000-1000-8000-00805F9B34FB` |

---

## 全部命令速查

### 步态控制

| 命令 | 效果 | 应答 |
|------|------|------|
| `G` | **站立** — 12舵机 50ms 错开，逐一到 STAND_POSE | `OK:STAND` |
| `T` | **Trot 对角小跑** — 800ms 斜坡从站姿渐入 | `TROT` |
| `A` | **单步前进 90°** — 自动切 Trot，立刻到位停住 | `PH:90` |

### 舵机校准

| 命令 | 效果 | 应答 |
|------|------|------|
| `1`~`12` | 切换校准舵机号 | `SW:S3` |
| `角度` | 当前舵机设角度，需确认 | `SET:S3:150?` |
| `舵机:角度` | 指定舵机设角度，需确认 | `SET:S3:150?` |
| `Y` | 确认执行 | `OK:S3:150` |
| `N` | 取消 | `CANCEL` |

---

## 上电状态

12 路 PWM 全开但 CCR=0，舵机全部松弛不动。主循环跑 `Gait_Update()`，默认 STAND 模式，delta=0。静默等待。

---

## 典型操作流程

### 调试步态

```
G  →  站立
A  →  动作1 抬腿前伸 (phase=0)   回复 PH:0
A  →  动作2 踏地后扫 (phase=90)   回复 PH:90
A  →  动作3 蹬地后推 (phase=180)  回复 PH:180
A  →  动作4 复位前摆 (phase=270)  回复 PH:270
A  →  循环回动作1
G  →  站立
```

### 连续行走

```
G  →  站立
T  →  800ms 渐入 Trot → 持续走
G  →  站立
```

### 校准舵机

```
3        →  切到舵机3
150      →  SET:S3:150?
Y        →  舵机3转到150°
5:120    →  SET:S5:120?
Y        →  舵机5转到120°
```

---

## G 命令电流说明

12 舵机 50ms 错开逐一设角度，总耗时 600ms。当前外展未接，只写 8 舵机（大腿+小腿），总耗时 400ms。
