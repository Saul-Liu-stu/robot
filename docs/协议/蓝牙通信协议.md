## 全部命令速查

### 步态控制（3D IK + walk_gait 版）

| 命令 | 效果 | 应答 |
|------|------|------|
| `G` | **站立 = 狗高站姿 280** — 前后正常膝，站高 280mm（反折膝先翻膝再升），5ms 平滑循环渐进 | `STAND...` → `OK:STAND` |
| `H` | **狗姿态高站姿** — 前后腿正常膝，站高 280mm（行走/越障用） | `HIGH` |
| `K` | **前顶高站姿** — 前腿反折膝 + 后腿正常，站高 280mm | `KNEE` |
| `L` | **低趴（前顶版）** — K 姿态趴到 220mm（前后足 ±120 对称展开） | `LOW` |
| `M` | **低趴（后顶版）** — 前腿狗腿正常 + 后腿反折膝往前突，趴到 220mm，重心集中 | `REAR` |
| `P` | **后顶高站姿** — 前腿狗腿正常 + 后腿反折膝往前突，站高 280mm（M 的高姿态版） | `REARH` |
| `X:20` | **前倾修正** — 足端前移 20mm（身体后坐），站立/行走同时生效，`X:-10` 反向 | `XSH:20` |
| `I` | **IMU 上报开关** — 10Hz 角度流（`R,x,P,y,Y,z,520` 帧），再按关闭 | `IMU:ON` / `IMU:OFF` |
| `Z` | **坡度功能开关** — 当前姿态采样 2s 标定零偏并开启（每姿态单独存）；再按关闭。仅在轮式模式（R）下生效 | `CALIB...` → `SLOPE:ON` / `SLOPE:OFF` |
| `Q:i:v` | **坡度参数在线调** — i: 0=lpf_alpha 1=up_thr 2=hyst 3=gain 4=shift_max，v 为浮点值（如 `Q:3:3.5`） | `AT:OK` |
| `A` | **单步调试** — 首次进相位0，之后每次 +1/4 周期，平滑过渡后停住 | `PH:0` / `PH:90` / `PH:180` / `PH:270` |
| `T` | **连续 Trot** — 纯 trot（无重心横移），停电机、恢复参数、相位从0开始 | `TROT` |
| `E` | **转圈动作** — trot + 重心横移（定死 15mm）；`E`/`E:1` 顺时针，`E:0` 逆时针 | `SWAY:1` / `SWAY:-1` |
| `W` | **越障模式** — 四轮 30% 前进 + 高站姿 280mm + 对角交替抬腿 70mm（原地抬不扫步；任何腿反折膝都会先翻膝回正常再开走） | `CLIMB` → `FLIP` |

### 电机控制

| 命令 | 效果 | 应答 |
|------|------|------|
| `R` | **一键滚动** — 四电机 30% 正转 | `ROLL` |
| `B` | **一键后退** — 四电机 30% 反转 | `BACK` |
| `S` | **一键停** — 四电机全停 | `STOP` |
| `M0:50:1` | 电机A 50%占空比 正转 | `MA:50:1` |
| `M1:30:0` | 电机B 30% 反转 | `MB:30:0` |
| `M2:100` | 电机C 100% 正转（方向缺省=正转） | `MC:100:1` |
| `M0:0` | 电机A 停止 | `MA:0:1` |

- 电机号 `0~3` = A/B/C/D
- 速度 `0~100`（0 = 停止）
- 方向 `1`=正转, `0`=反转, 可省略
- A/B 电机的方向已在驱动层纠正（接线相反），命令语义统一

### 舵机校准（已启用，重装舵机臂后标定用；标定完可改回 `#if 0`）

舵机编号映射：

| 编号 | 关节 |
|------|------|
| 1~4 | 外展（FL / FR / RL / RR） |
| 5~8 | 大腿（FL / FR / RL / RR） |
| 9~12 | 小腿（FL / FR / RL / RR） |

| 命令 | 效果 | 应答 |
|------|------|------|
| `1`~`12` | 切换校准舵机号 | `SW:S3` |
| `角度` | 当前舵机设角度，需确认 | `SET:S3:150?` |
| `舵机:角度` | 指定舵机设角度，需确认 | `SET:S3:150?` |
| `Y` | 确认执行 | `OK:S3:150` |
| `N` | 取消 | `CANCEL` |

> ⚠️ 校准必须在上电后直接进行（CALIB 模式）。一旦发过 `G/T/H/L`，5ms 控制循环会持续写全部舵机，手动指令会被覆盖。若要恢复校准，重新上电。

> dir 不需要重测：只转动舵机臂重新对零只影响 `zero_deg`，dir 由舵机本体安装朝向决定。若舵机本体朝向也变了，需用 +10° 法重测 dir。

## IMU 姿态上报（上行数据流，I 命令开关）

- 发 `I` 开启、再发 `I` 关闭，开启后 **10Hz** 固定频率（与模块输出率一致）
- 格式（参考 adc_10 多参数采集系统风格，全整数传输）：

```
R,<roll_x10>,P,<pitch_x10>,Y,<yaw_x10>,520\r\n
例: R,-12,P,34,Y,1579,520
```

| 字段 | 含义 | 说明 |
|------|------|------|
| R | 横滚 roll | 整数 = 角度×10（0.1° 分辨率，-12 = -1.2°） |
| P | 俯仰 pitch | 同上；**前倾为正、后倾为负**（实测约定） |
| Y | 偏航 yaw | 同上（Z 轴漂移，不可长期参考） |
| 520 | 帧尾 | 校验标记，末字段非 `520` 的帧丢弃 |

- 帧类型判定：逗号分割后 7 个字段且末字段为 `520` → IMU 帧
- IMU 模块：WT9011G4K，115200bps，TX → PD6(USART2_RX)
- 上报与命令回显交错出现，上位机按帧尾/前缀分发解析

## 上电状态

1. 12 路舵机 PWM 全开（CCR=0 无脉冲）
2. **外展 4 舵机**（1~4）100ms 错开锁到站姿角：95 / 94 / 50 / 150°
3. 大腿/小腿 8 舵机保持松弛（指令角已预置为 IK 站姿解，首次 G 不跳变）
4. **电机 PWM 启动但 CCR=0**，STBY 拉高待命，不转
5. 蓝牙发 `READY\r\n` 自检
6. 模式 = CALIB（5ms 控制循环不碰舵机），等命令

## 步态说明（3D IK + walk_gait）

```
5ms 控制节拍 (200Hz):
  模式机: CALIB(不动) / STAND(站立) / TROT(行走) / STEP(单步冻结)

  STAND: 足端目标 = 前移修正 + 低趴外伸(站高越低前后腿越外伸)
         → 3D IK(前后腿膝分支独立: 正常/反折) → 12舵机
  TROT:  足端轨迹(支撑60%: 贴地+30→-30mm; 摆动40%: 椭圆抬25mm)
         → 3D IK → 12舵机
         E 转圈时额外叠加重心横移 ±15mm (E:0 反向)
  STEP:  同上但行走时刻冻结, A 每次 +1/4 周期

  指数平滑: 指令角 += (目标-指令角)×速率(站0.12/走0.20) → 批量写12路
```

参数（walk_gait.c 的 g_walk_params，运行时可改）：

| 参数 | 值 |
|------|-----|
| step_len 步幅 | 60mm（T 行走）/ 0mm（W 越障原地抬）/ 30mm（F 横移，已暂停） |
| step_h 抬腿 | 25mm（T 行走）/ 70mm（W 越障）/ 40mm（F 横移，已暂停） |
| period 周期 | 1.2s |
| duty 支撑比 | 0.6 |
| stand_h 站高 | 280mm（默认，G/H/K/P 高姿态）/ 220mm（L/M 低趴，四轮驱动） |
| foot_x_shift 前移修正 | 15mm（最终实测默认值），X: 命令仍可在线调，正值修正前倾 |
| y_shift 重心横移 | 15mm（定死，仅 E 转圈动作用），E:0 取反为逆时针 |

## 典型操作流程

### 调试步态

```
G  →  站立（平滑渐进）
A  →  相位0 (支撑起始)            PH:0
A  →  相位1/4 (FL+RR抬腿)         PH:90
A  →  相位1/2 (对角交换)          PH:180
A  →  相位3/4 (FR+RL抬腿)         PH:270
A  →  循环
G  →  平滑回站姿
```

### 连续行走

```
G  →  站立
T  →  相位从0起, 平滑渐入 → 连续 Trot (1.2s/周期, 步幅60mm)
G  →  平滑回站姿
```

### 五姿态切换（H / K / L / M / P）

```
H  →  狗姿态高站姿 280mm (前后腿正常膝)  → HIGH → 配 T 行走 / W 越障
K  →  前顶高站姿 280mm (前腿反折 + 后腿正常) → KNEE
L  →  低趴 220mm = K 姿态趴下 (前反折, 前后足±120对称) → LOW → 配 R/B/S 车轮跑
M  →  低趴 220mm = 后顶版 (前腿狗腿正常 + 后腿反折膝往前突, 重心集中) → REAR
P  →  后顶高站姿 280mm = M 的高姿态版 → REARH
```

**翻膝机动**（切换时自动执行，指定腿组）：

```
需要翻的腿组足端沿地面伸到直腿点(此点两膝分支连续) → 翻转分支 → 收回到站姿点
前腿往+伸, 后腿往-伸; 回显 FLIP, 膝离地全程 ≥110mm, 总时长约 3s
```

- K↔L、M↔P 同分支，直接升降，无翻膝；其余组合自动识别需翻的前/后腿组
- 上电默认狗姿态（前后正常膝，站高 280），G = 狗高站姿（等价于按 H）
- ⚠️ 低趴 220mm（L/M）只用于四轮驱动，不要发 T。要走路先按 G 或 H。

### 前倾修正

```
身体前倾(重心偏前) → 抬前脚被压/拖地
X:10  →  足端前移 10mm, 观察身体是否回正    XSH:10
X:20  →  不够再加大                          XSH:20
X:-10 →  反了就往回调                        XSH:-10
```

- 站立/行走同时生效，行走中也可实时调
- 调好后把默认值写进 `g_walk_params.foot_x_shift` 即可永久生效

### 轮式滚动

```
R  →  四电机 30% 正转 → 往前滚
B  →  四电机 30% 反转 → 往后退
S  →  四电机全停（急停）
M1:60:0  →  单电机B 60% 反转（单独调试）
```

### 越障模式（W）

```
W  →  四轮 30% 前进 + 自动切高站姿 280mm + 对角交替抬腿 70mm
      (FL+RR 与 FR+RL 两组各抬 0.48s / 停 0.72s 交替, 无重心横移)
S  →  只停电机, 腿继续抬 → 要停腿再发 G
G  →  腿回站姿
T  →  退出越障回纯行走 (自动停电机、恢复步幅60/抬腿25)
```

### 转圈动作（E）

```
E    →  trot + 重心横移15mm, 顺时针原地转圈    SWAY:1
E:0  →  横移取反, 逆时针原地转圈               SWAY:-1
G    →  回站姿停止转圈
```

### 坡度自适应（轮式爬坡）

```
L/M → 低趴姿态 → Z → 机器人静止2秒标定零偏 → SLOPE:ON
R  →  轮式滚动, 爬坡时自动检测:
      上坡(pitch长期均值低于-5°) → 足端整体后移(身体前压)
      → 前后腿载荷均衡 → 身体保持与坡面平行, 防后仰
S  →  停轮(功能保持开启, 回到平地后仍可用)
Z  →  再按关闭                          SLOPE:OFF
```

参数（默认值，`Q:` 在线调，调好写死）：

| # | 参数 | 默认 | 说明 |
|---|------|------|------|
| 0 | lpf_alpha | 0.002 | 坡度低通（约 2.5s 时间常数） |
| 1 | up_thr | 5° | 上坡判定阈值 |
| 2 | hyst | 2° | 退出迟滞 |
| 3 | gain | 3.5 mm/° | 每度坡度足端后移量 |
| 4 | shift_max | 40 mm | 后移上限 |

> 符号约定（实测）：前倾 = pitch 正 → 上坡 = pitch 负。
> 镇定层（站立自稳/行走镇定）暂缓，本层独立生效。

### 横移走（F 螃蟹步）— 已暂停（实测效果不佳，代码保留）

```
F     →  自动切狗姿态280 + 四腿外展横向扫步 + 原地抬腿40mm, 身体向右
F:0   →  向左横着走
G     →  腿回站姿停止横移
```

### 校准舵机（已启用，上电后、发 G/T 前使用）

```
5        →  SW:S5
150      →  SET:S5:150?
Y        →  OK:S5:150
```

## 调试回显

| 上行 | 含义 |
|------|------|
| `UNK:xxx\r\n` | 固件收到无法识别的命令，原样回显（排查用） |
| `READY\r\n` | 上电自检（TX/DMA 通道正常） |
| `FLIP\r\n` | 翻膝机动开始（H/K/L/M/P 姿态切换中需翻膝时自动触发，约 3s 完成） |
| `CALIB...` / `SLOPE:ON` / `SLOPE:OFF` | 坡度功能：标定开始 / 标定完成自动开启 / 关闭 |
| `IMU:ON` / `IMU:OFF` | IMU 上报开关回显 |
| `R,x,P,y,Y,z,520` | IMU 角度帧，I 开启后 10Hz（见"IMU 姿态上报"节） |
| `DBG2:CR1=... ISR=...` | I 按下后的 USART2 寄存器 + 收发计数诊断（排查接收链用） |
| `IMU:NO DATA raw=N frames=N` | I 开启但 5s 无有效帧的告警（每 2s 一次，排查接收链用） |

## 已知兼容性注意

- STM32H7 D-Cache：TX 前刷缓存（`SCB_CleanDCache_by_Addr`），SRAM 缓冲区不回旧数据
- MPU Region 1 必须是 512KB 对齐的 `0x24000000`（整个 D1 RAM 非缓存）
