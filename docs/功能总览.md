## 三、姿态系统（五姿态 + 翻膝）

### 3.1 五姿态

| 姿态 | 站高 | 前腿膝 | 后腿膝 | 用途 |
|------|------|--------|--------|------|
| G/H 狗高 | 280 | 正常 | 正常 | 行走、越障 |
| K 前顶高 | 280 | 反折 | 正常 | 展示/特殊 |
| P 后顶高 | 280 | 正常 | 反折 | 展示/特殊 |
| L 前顶低趴 | 220 | 反折 | 正常 | 四轮驱动 |
| M 后顶低趴 | 220 | 正常 | 反折 | 四轮驱动（重心集中） |

- 低趴姿态足端展开（L 四足 ±129.5 对称、M 前 +45/后 -120），膝高(几何) L 180mm、M 134/112mm，实际离地再 +54mm（108mm 轮径），支撑中心在身下
- 上电默认：狗姿态 280mm（`G` 即可站立）

### 3.2 翻膝机动

- 前后腿膝分支（正常/反折）在"直腿点"（足端伸到 L1+L2）连续
- 切换需要翻膝的组合时自动执行：足端伸到直腿点 → 翻转分支 → 收回，约 3s
- K↔L、M↔P 同分支直接升降，无翻膝
- 全程膝离地 ≥110mm，回显 `FLIP`

## 四、步态系统

| 功能 | 说明 |
|------|------|
| `T` 纯 Trot | 对角抬腿行走 + **四轮 10% 助走**，步幅 60mm / 抬腿 25mm / 周期 1.2s / 支撑比 0.6；退出行走（G 等）自动停轮 |
| `T:-1` 倒走 | 负步幅反向 trot + 四轮 10% 反向助走 |
| `W` 越障 | 高站姿 280 + 对角**原地**抬腿 50mm（足端不前后移、不动轮；70mm 时后腿舵机贴 270° 极限抬不动）；**自稳自动跟随**（支撑腿 z 补偿，防对角支撑翘板，需 Z 标定）；前进由 `V:速度:转向:1` 无倾斜轮盘控制，边抬腿边走，可跨 ~30mm 障碍（108mm 大轮） |
| `E`/`E:0` 转圈 | trot + 15mm 重心横移，原地顺/逆时针旋转 |
| `A` 单步 | 相位冻结，每次 +1/4 周期，调试用 |

## 五、轮式系统

### 5.1 一键与单控

- `R` 四轮 30% 前进 / `B` 后退 / `S` 急停
- `M电机号:速度[:方向]` 单电机控制（2026-08-20 重接线后四路同极性，无方向补偿）

### 5.2 摇杆遥控（APP 第四页）

```
命令: V:速度:转向[:模式]   范围 −50~+50, V 值 = 占空比% (1:1)
      速度负=后退, 转向负=左转/正=右转
差速: 左轮 = 速度+转向, 右轮 = 速度−转向 (限幅±100)
斜坡: 0.5s 渐变到目标占空比 (起步不猛)
回中: V:0:0 → 渐停 + 回平 (急停用 S)
回显: 无 (高频流, APP 不要等应答)

模式1 (第二套轮盘, V:sp:st:1):
- 无倾斜补偿: 起步不低头/不压弯
- 反折膝自动翻回 H (回 FLIP), 翻完前驱动忽略; 正常膝按当前站高行驶 (H:230 蹲低爬陡坡)
- 自稳自动跟随: 平台水平由 IMU 自稳层保持 (需先 Z 标定 H, 无需 L:1)
```

### 5.3 倾斜平衡（V 自动附带）

| 场景 | 动作 | 幅度 |
|------|------|------|
| 起步加速 | 平台低头（前腿 z 缩短/后腿 z 伸长） | ∝(命令−实际占空比)，上限 15mm ≈4.5° |
| 刹车减速 | 平台抬头 | 反向 |
| 左/右转 | 向弯内压弯（左右 z 差动） | ∝转向量，上限 10mm ≈2.7° |
| 到速 | 编码器平台期判定（300ms 窗口增量 <2 RPM）→ 回平 | 0.3s 渐变 |
| 兜底 | 斜坡完成自动回平（编码器无信号也可用） | — |

## 六、站立自稳（H/K 高站姿）

> 2026-08-23 坡度自适应层已删除（未实测、与自稳职责重叠），Z 改为纯自稳标定。

- `Z` 平地标定（存 pitch/roll 零偏，每姿态分存）→ `L:1` 开启 / `L:0` 关闭
- 仅 **H（狗高）**、**K（前顶高）** 280mm 生效；P 后顶站不启用（RR 大腿余量仅 7°）
- 原理：身体往哪边倾哪边腿伸长（10Hz 低通约 0.6s），单腿 z 补偿上限**按站高动态算**（`304.6 − 站高`）
- **死区 ±1°**（2026-08-23 实测"太敏感"反馈）：微小晃动不响应，软死区无阶跃
- 补偿坡度能力（pitch，直腿点几何极限）：280 站高 ≈7.5° / 230 ≈23° / 220 ≈26.5° / 210 ≈30°；超出钳位、保留剩余倾斜
- 爬陡坡：`H:230` 边开边蹲 → `V:..:1` 上坡保持水平 → 回平地 `H` 站起
- 仅站立静止或 **V 模式1 无倾斜驱动中**叠加；行走/站起/翻膝/收纳/坐姿中自动清零

## 七、传感数据上报

| 流 | 开关 | 频率 | 帧格式 |
|----|------|------|--------|
| IMU 角度 | `I` | 10Hz | `R,x,P,y,Y,z,520`（×10 定点，0.1°） |
| 编码器转速 | `J` | 10Hz | `E,e0,e1,e2,e3,520`（RPM） |

- 帧尾 520 校验；上报与命令回显交错，上位机按前缀分发
- IMU 符号：前倾 P 正、后倾 P 负（上坡 = P 负）

## 九、常用操作流程

```
上电 → READY
  ├─ G → T         纯行走
  ├─ G → W         越障
  ├─ G → E/E:0     转圈
  ├─ L/M → R/B/S   四轮驱动（低趴）
  ├─ V:30:0        摇杆遥控（倾斜自动）
  ├─ I / J         传感数据显示
  └─ X:毫米        前倾修正
```
