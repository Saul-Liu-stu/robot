# 步态实现说明（舵机角度空间直驱）

> 无 IK、无几何坐标。步态直接在 12 个舵机角度上做偏移。

---

## 一、数据流

```
Gait_Update()  每帧调用
  │
  ├─ 全局相位推进: g_phase = (g_phase + Δ) % 360
  │
  ├─ 逐腿: local_phase = (g_phase + offset[腿]) % 360
  │
  ├─ 摆动相(0~179°): swing_traj  → thigh_delta, calf_delta
  ├─ 支撑相(180~359°): stance_traj → thigh_delta, calf_delta
  │
  └─ 舵机角度 = STAND_POSE[腿][关节] + delta
       → CLAMP(0, 270) → Leg_SetJoint → NewServo_SetAngle → TIM CCR
```

关键：**STAND_POSE 是唯一基准。** 所有运动从这个姿态出发，加减偏移量。

---

## 二、STAND_POSE — 站姿基准（实测标定值）

```
            {外展, 大腿, 小腿}
Leg1 左前:  { 98,  240,  153}
Leg2 右前:  { 94,   35,   74}
Leg3 左后:  { 50,  135,  220}
Leg4 右后:  {150,  200,   30}
```

这些值是你用蓝牙逐个舵机测出来的，代表机器人四条腿自然站立时，每个舵机的角度。**改了 STAND_POSE，站姿就变了，步态也跟着变。**

---

## 三、步态参数（可调）

| 参数 | 默认值 | 含义 | 调大效果 |
|------|--------|------|---------|
| GAIT_STEP_LENGTH | 40 | 大腿最大偏移角 | 步子更大 |
| GAIT_STEP_HEIGHT | 30 | 小腿最大弯曲量 | 脚抬更高 |
| GAIT_CYCLE_MS | 800 | 完整周期时间 | 走更慢 |

这三个值都在 leg_config.h 里改。

---

## 四、全局相位 — 整个步态的时钟

一个 `uint16_t` 变量 `g_phase` 在 0~359 之间循环，每帧根据时间差推进：

```
如果 CYCLE_MS=800ms: 每度耗时 = 800/360 ≈ 2.2ms
主循环每帧 10ms → 每帧推进 ≈ 4.5°
```

相位 0→359 构成一个完整步态周期，回到 0 重新开始。

---

## 五、四条腿的相位偏移 — 步态的本质

每条腿的局部相位 = 全局相位 + 偏移量：

| 步态 | Leg1(左前) | Leg2(右前) | Leg3(左后) | Leg4(右后) | 效果 |
|------|-----------|-----------|-----------|-----------|------|
| STAND | 0 | 0 | 0 | 0 | 四腿同相，不动 |
| TROT | 0 | 180 | 180 | 0 | 对角同步，两腿交替 |
| WALK | 0 | 90 | 180 | 270 | 逐腿抬，一次一条 |
| CRAWL | 0 | 120 | 240 | 60 | 匍匐，重心更低 |

**TROT 举例：**

```
时刻 A (g_phase=0°):
  Leg1 local=0°   → 摆动（抬腿）
  Leg2 local=180° → 支撑（蹬地）
  Leg3 local=180° → 支撑（蹬地）
  Leg4 local=0°   → 摆动（抬腿）
  对角 1+4 同时抬，2+3 同时蹬。

时刻 B (g_phase=180°):
  Leg1 local=180° → 支撑（蹬地）
  Leg2 local=0°   → 摆动（抬腿）
  Leg3 local=0°   → 摆动（抬腿）
  Leg4 local=180° → 支撑（蹬地）
  对角 2+3 同时抬，1+4 同时蹬。
```

任何时候两条腿着地两条腿腾空，身体交替前推。

---

## 六、摆动相 vs 支撑相

每条腿的 360° 周期分两半：

```
  0°──────────180°──────────360°
  |   摆动相    |    支撑相    |
  腿在空中前摆    腿在地上后蹬
```

| 阶段 | 相位 | 大腿 delta | 小腿 delta |
|------|------|-----------|-----------|
| 摆动 | 0→179° | +40 → 0 → -40（前到后） | 0 → -30 → 0（三角波抬腿） |
| 支撑 | 180→359° | +40 → 0 → -40（后蹬复位） | 0（贴地不屈膝） |

### 大腿 delta：

```
  +40 ┤╲          ╲
      ┤ ╲          ╲
    0 ┤──┼──────────┼──
      ┤   ╲          ╲
  -40 ┤    ╲          ╲
      0°───90°──179°  180°──270°──359°
       摆动相           支撑相
```

大腿 delta 在摆动相和支撑相里**轨迹完全相同**——从 +STEP_LENGTH 线性降到 -STEP_LENGTH。区别只是语义：摆动相是往前迈，支撑相是往后蹬。

### 小腿 delta：

```
    0 ┤╲          ╱   ──────────────
      ┤ ╲        ╱
  -30 ┤──╲──────╱──   支撑相 calf_delta=0
      0°──90°──179°   180°──────────359°
        摆动相           支撑相
```

小腿只在摆动相弯膝抬腿，支撑相伸直贴地。

## 七、最终舵机角度计算（以 Leg1 Trot 摆动相为例）

假设 STAND_POSE[Leg1][THIGH]=240，STEP_LENGTH=40，当前 phase=45°：

```
thigh_delta = 40 × (90-45) / 90 = 20
最终大腿舵机 = 240 + 20 = 260 → CLAMP(0,270) → 260 ✓
```

假设 STAND_POSE[Leg1][CALF]=153，STEP_HEIGHT=30，当前 phase=45°：

```
calf_delta = 30 × 45 / 90 = 15
         = -15                        （取反，弯膝）
最终小腿舵机 = 153 + (-15) = 138 → CLAMP(0,270) → 138 ✓
```

---

## 八、外展关节

当前所有步态中外展保持不动，取 `STAND_POSE[leg][JOINT_ABD]`（你标定的 98/94/50/150°）。后续加侧移/转弯时才需要在外展上加偏移。

---

## 九、CLAMP 限幅保护

每次计算出最终舵机角度后，CLAMP(0, 270) 兜底。即使偏移量过大，舵机也不会收到超出 0~270 的脉宽。你的全部限幅已扩到 0~270。

---

## 十、如何接入主循环

在 main.c 的 while(1) 中加入：

```c
Gait_Update();
```

步态引擎会自动推进相位、计算偏移、写入 12 路舵机。不加这行就不走。

---

## 十一、蓝牙控制

连上后可以：
- `G` → 站姿（cmd_stand，逐舵机错开）
- 后续加步态切换命令（如 `T` → Trot, `W` → Walk）调用 `Gait_SetType()`
